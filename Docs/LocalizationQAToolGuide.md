# Localization QA 툴 사용법

모든 UI에 나오는 모든 문구를, 18개 언어와 게임이 지원하는 해상도별로 **실제 게임과 같은 화면**에서 보고 판정하는 에디터 툴입니다.
칸 넘침·줄바꿈·잘림·글리프 누락(□)을 사람이 눈으로 검수하고, 자동 검사로 의심 구간을 먼저 찾을 수 있습니다.

메뉴: **Tools ▸ Localization ▸ Localization QA**

| 메뉴 | 용도 |
|---|---|
| 사람 검수 (UI 문구) | 화면별로 모든 문구를 언어별로 보고 OK/NG를 기록합니다. **주로 쓰는 창입니다.** |
| 자동 검사 (넘침·잘림·글리프) | 칸 넘침 등을 자동으로 찾습니다. 플레이 중 실측, 프리팹 정적 검사, 문구 전수 검사가 있습니다. |
| 검수 진행 현황 | 언어별·화면별 진행률과 NG 수를 한눈에 봅니다. |

> 에디터 전용 코드라 빌드에는 포함되지 않습니다.

---

## 1. 처음 한 번 할 일

1. **검수자 이름 확인**: 사람 검수 창 상단의 `검수자` 칸. 판정마다 이 이름과 시각이 기록됩니다. (기본값은 Unity 계정 이름)
2. **최신 데이터 받기**: 다른 사람의 판정을 `git pull`로 받았거나 번역 JSON이 바뀌었으면 `다시 읽기`를 누릅니다.
3. **UI가 바뀌었을 때만**: 프리팹에 텍스트를 추가·삭제했다면 `목록 갱신`을 누릅니다. 기존 연결과 판정은 그대로 유지됩니다.

---

## 2. 사람 검수 창

```
┌ 툴바: 목록 갱신 · 다시 읽기 · [문구별 비교 | 언어별 검수] · 언어 · 필터 · 해상도 ─────────┐
│ 진행 현황 · 연결 안 된 문구 N개 · 칸 크기 · 배치 · 창 최대화 · 검수자 · NG CSV · 자동 검사 창 │
├──────────────┬──────────────────────┬──────────────────────────────────┤
│ 화면 목록     │ 그 화면의 문구 목록    │ 화면 그림 (바둑판)                 │
│ (진행률 막대) │ ▸ [그리는 화면] 칸     │                                  │
│ TentUI        │   키 / 한국어 원문     │                                  │
│ ESCMenu ...   │                      ├──────────────────────────────────┤
│              │                      │ 상세: 문구 · 자동 검사 결과 ·       │
│              │                      │ 표시 형식 · 견본 값 · NG 사유      │
└──────────────┴──────────────────────┴──────────────────────────────────┘
```

### 화면 목록 (왼쪽)

- **UIView 화면 단위**로 묶여 있습니다. 화면이 쓰는 부품도 함께 나옵니다.
  - 예) **TentUI** = 특성 화면 본체 + 툴팁(특성 이름·레벨·설명·수치·비용) + 키 가이드
  - 예) **ESCMenu / UIView_MainMenu** = 각 메뉴 + 옵션 창(두 화면 모두에 나옵니다)
  - 예) **HUD_UI** = 던전 상태 배너(숲 이름·상태 문구) 등
- 부품의 판정은 공유됩니다. 옵션 창 문구를 ESCMenu에서 판정하면 UIView_MainMenu에서도 판정된 것으로 보입니다.
- 막대는 진행률, `NG n`은 NG 수, `미연결 칸 n`은 아직 문구가 연결되지 않은 텍스트 칸 수입니다.

### 보기 방식 두 가지

| 보기 | 이럴 때 | 화면 |
|---|---|---|
| **문구별 비교** | 레이아웃 담당자가 한 문구를 모든 언어로 비교할 때 | 고른 문구 하나를 18개 언어로 나란히 (같은 영역을 잘라서) |
| **언어별 검수** | 언어 담당 검수자가 자기 언어만 쭉 볼 때 | 고른 언어 하나로 화면의 모든 문구를 바둑판으로 |

언어별 검수에서는 각 칸 아래에 어느 화면·칸의 문구인지, 상세 영역에 **한국어 원문**이 함께 나옵니다.

### 크게 보기: 배치 · 창 최대화

툴바의 배치 드롭다운(`바둑판` / `가로 스크롤` / `세로 스크롤`)으로 그림을 늘어놓는 방식을 고릅니다.

| 배치 | 그림 | 넘기는 법 |
|---|---|---|
| **바둑판** (기본) | 칸 크기만큼 여러 장을 한 화면에 | 세로 스크롤 |
| **가로 스크롤** | 한 장이 그림 영역 높이를 꽉 채움 | 휠(또는 Shift+휠)·←→ 로 옆 언어/문구 |
| **세로 스크롤** | 한 장이 그림 영역 폭을 꽉 채움 | 휠·↑↓ 로 아래 언어/문구 |

- `창 최대화`를 누르면 검수 창이 Unity 전체를 덮어, 가로/세로 스크롤 배치에서 한 장을 아주 크게 봅니다. 다시 누르면 원래 자리로.
- 가로/세로 스크롤에서는 `전체 화면`을 함께 켜면 칸 주변이 아니라 **UI 전체**를 한 장씩 넘기며 볼 수 있습니다. (언어별 검수에서도 동작)
- 고른 칸으로 자동 스크롤되고, 단축키(OK/NG/Space 등)는 바둑판과 같습니다.

### 칸(셀) 읽는 법

- **노란 테두리**: 텍스트 칸(RectTransform)
- **빨간 테두리**: 자동 검사가 문제를 찾은 글자 영역 (칸 초과 등). 아래에 `자동: 칸 초과`처럼 표시됩니다.
- **번역 없음**: 이 언어 번역이 비어 있어 영어(중남미 스페인어는 스페인어) 문구가 대신 나오는 칸
- **테두리 색**: 회색 = 미검토, 초록 = OK, 빨강 = NG, 주황 = 번역 바뀜(판정 후 번역이 수정되어 다시 봐야 함)
- 더블클릭하면 크게 봅니다. `전체 화면` 토글을 켜면 칸 주변이 아니라 UI 전체를 봅니다.
- `칸 크기` 슬라이더로 그림 크기를 조절합니다. (바둑판일 때)
- **화면에 안 보임**: 툴이 칸을 보이게 하려고 모든 장치(아래 8장)를 써도 글자가 그려지지 않은 칸입니다. 칸 아래와 상세 영역에 표시됩니다.
  나오면 그 UI가 게임에서 어떻게 열리는지 확인이 필요하다는 뜻이니 툴 담당에게 알려 주세요. (현재 전 화면 0건)

### 단축키

목록이나 그림을 한 번 클릭한 상태에서 씁니다. (입력 칸에 커서가 있으면 동작하지 않습니다)

| 키 | 문구별 비교 | 언어별 검수 |
|---|---|---|
| ← → ↑ ↓ | 언어 칸 이동 | 문구 칸 이동 |
| `1` / `O` | OK | OK |
| `2` / `X` | NG | NG |
| `0` / `Delete` | 판정 지우기 | 판정 지우기 |
| `Space` | OK 후 다음 언어 | OK 후 다음 문구 |
| `Enter` | 아직 안 본 언어를 모두 OK로 하고 다음 문구 | OK 후 다음 문구 |
| `PageDown` / `PageUp` | 다음 / 이전 문구 | 다음 / 이전 언어 |

### NG 처리

- NG 칸을 고르고 아래 `NG 사유`에 이유를 적습니다. (사유를 적으면 자동으로 NG가 됩니다)
- 툴바 `NG 목록 CSV`로 화면·칸·키·언어·문구·사유·검수자를 엑셀용 CSV로 내보내 번역·UI 담당자에게 전달합니다.
- 번역이 수정되면 그 칸은 자동으로 **번역 바뀜**이 되어 다시 검수 대상이 됩니다.

### 필터와 검색

- `할 일 남은 것`(기본): 미검토·번역 바뀜·문구 연결 필요가 남은 것만
- `NG 있는 것`: NG가 하나라도 있는 것만
- `전체`: 모두
- 가운데 목록 위 검색창은 키·한국어 원문·칸 이름으로 찾습니다.

## 3. 해상도

툴바 오른쪽 드롭다운에서 고릅니다. 게임 옵션의 창모드 해상도 8개와 흔한 전체화면 모니터 해상도 9개가 있습니다.

게임 UI 캔버스는 `화면 세로 ÷ 360`을 반올림한 정수 배율로 그려지므로(`PixelPerfectCanvasScaleApplier`), 툴도 그 해상도에서의 **실제 캔버스 크기**로 UI를 띄웁니다.

| 해상도 | 캔버스 |
|---|---|
| 16:9 (640×360 ~ 2560×1440) | 640×360 |
| 16:10 (640×400 ~ 2560×1600) | 640×400 |
| 전체화면 1366×768 | 683×384 |
| 전체화면 1600×900 | 800×450 |
| 전체화면 2560×1080 | 853×360 |

판정(OK/NG)은 해상도와 관계없이 언어별로 하나입니다. 해상도를 바꿔 다시 확인하고 문제가 있으면 NG 사유에 해상도를 적어 주세요.

## 4. 칸에 문구 연결하기

이 게임은 문구를 전부 코드에서 넣기 때문에, 툴은 "어느 칸에 어떤 문구가 들어가는지"를 따로 기록합니다(`Review/Items.json`).
현재 모든 칸이 코드 분석으로 연결되어 있으므로, **UI나 코드가 바뀌었을 때만** 손대면 됩니다.

### 문구 추가 / 연결

1. 가운데 목록에서 칸(또는 그 칸의 문구)을 고릅니다.
2. `이 칸에 문구 추가…`(미연결 칸이면 `문구 연결…`)를 누릅니다.
3. 문구 고르기 창에서 파일·검색어로 거르고 체크한 뒤 `이 칸에 n개 추가`.
   - 프리팹 이름과 닮은 JSON 파일이 먼저 선택됩니다. (예: HUD_Message → MessageHUD)
   - `보이는 n개 전부 선택`으로 한꺼번에 추가할 수 있습니다. (예: 검색어 `dungeonState` → 던전 상태 문구 전부)

### 그 밖의 정리

- **목록에서 빼기**: 그 칸에 실제로는 나오지 않는 문구일 때. (뺀 연결은 자동 추론이 되살리지 않습니다)
- **번역 대상 아님**: 숫자·이름·고정 영문처럼 번역하지 않는 칸일 때.
- **연결 안 된 문구 N개**(툴바): 어떤 칸에도 연결되지 않은 문구. 0이 되면 모든 문구가 검수 대상입니다.
  게임에서 쓰지 않는 문구(폐기된 UI 등)는 "미사용"으로 기록되어 이 숫자에서 빠집니다.
- **플레이 중 자동 연결**: 자동 검사 창의 `자동 수집`을 켜고 게임을 돌아다니면, 화면에 나온 문구가 그 칸에 자동으로 연결됩니다.

### 표시 형식과 견본 값 (상세 영역)

| 칸 | 쓰는 경우 | 예 |
|---|---|---|
| **표시 형식** | 코드가 문구에 숫자·태그를 붙여 보여줄 때. `{text}` 자리에 문구가 들어갑니다. | `{text} : 3 / 5` (툴팁 레벨), `<COLOR=58D7F2><WAVE>{text}</WAVE></COLOR>` |
| **견본 값** | 문구의 `{0}`, `{1}` … 자리에 넣을 값. `\|`로 구분합니다. 비우면 `999`. | `5` (처치 수 1~10 구간), `12\|30\|42` |

## 5. 자동 검사 창

사람 검수 전에 의심 구간을 먼저 찾을 때 씁니다. 결과는 아래 목록에 모이고, 항목을 고르면 그 언어의 화면이 미리보기로 나옵니다.
`사람 검수 창에서 보기`를 누르면 그 문구를 검수 창에서 바로 엽니다.

| 탭 | 설명 |
|---|---|
| **플레이 검사** | 플레이 중 화면에 떠 있는 텍스트를 실측합니다. 가장 정확합니다. |
| **프리팹 검사** | 플레이 없이 UI 프리팹 전부를 모든 언어로 띄워 잽니다. (약 3초) |
| **문구 검사** | 모든 키 × 모든 언어의 빈 문구, 번역 누락, 폰트에 없는 글자(□)를 봅니다. |
| **설정** | 검사할 언어, 해상도, 허용 오차, 판정 항목을 고릅니다. |

### 플레이 검사

1. `▶ 플레이 시작` 후 확인할 UI를 게임에 띄웁니다.
2. `모든 언어 순회 검사`: 언어를 하나씩 바꿔 가며 화면을 검사하고 스크린샷을 남깁니다. 끝나면 원래 언어로 돌아옵니다.
3. `모든 해상도 × 언어 순회`: Game 뷰 해상도까지 바꿔 가며 반복합니다. 끝나면 원래 해상도로 돌아옵니다.
4. `자동 수집`을 켜면 게임을 돌아다니는 동안 지금 언어로 보이는 텍스트를 계속 검사하고, 문구를 검수 목록에 연결합니다.

- 게임 화면 위 **노란 박스** = 텍스트 칸, **빨강/주황 박스** = 오류/경고가 난 글자 영역
- 스크린샷은 프로젝트 루트 `LocalizationQA/Captures/`에 저장됩니다. (커밋되지 않음)
- **Game 뷰가 화면에 보이는 상태**여야 스크린샷이 찍힙니다.
- 언어 순회는 설정 파일(`Settings.json`)에 언어를 기록하지만, 끝나거나 플레이를 멈추면 원래 언어로 되돌립니다.
- 첫 실행 언어 선택 팝업처럼 언어 변경에 반응하지 않는 화면은 순회로 바뀌지 않습니다. 그 화면 자체의 화살표로 넘겨 보세요.

### 자동 검사가 찾는 것

| 종류 | 의미 |
|---|---|
| 칸 초과 | 줄이 칸 높이를 넘거나, 줄바꿈 없는 글자가 칸 폭을 넘음 |
| 글자 살짝 넘침 | 가로로 몇 픽셀 삐져나옴 |
| 잘림·말줄임 | 말줄임·잘라내기·마스킹 때문에 문구 일부가 안 보임 |
| 글리프 없음(□) | 그 언어 폰트(폴백 포함)에 없는 글자 |
| 단어 중간 끊김 | 라틴·키릴 단어가 칸이 좁아 둘로 쪼개짐 |
| 배경 영역 초과 | 글자가 버튼·패널 배경 밖으로 나감 |
| 화면 밖 | 글자가 화면 가장자리 밖으로 나감 (플레이 검사만) |
| 자동 줄바꿈 | 원문보다 줄이 늘어남 (참고) |
| 번역 없음 / 빈 문구 | 문구 검사 결과 |

`원문(한국어)에도 있는 문제 숨기기`(기본 켜짐)는 한국어에서도 똑같이 생기는 문제를 숨겨, 로컬라이징 때문에 생긴 문제만 보여줍니다.

---

## 6. 진행 현황

- **언어별 진행률**: 언어마다 완료율, OK·NG·번역 바뀜·남은 수
- **화면 × 언어 표**: 칸의 숫자는 완료율(%), 빨간 칸은 NG가 있는 곳. **칸을 누르면** 그 화면을 그 언어로 언어별 검수 창에서 엽니다.

## 7. 저장되는 파일

| 경로 | 내용 | 커밋 |
|---|---|---|
| `Assets/Scripts/Editor/Localization/LocalizationQA/Review/Items.json` | 칸 ↔ 문구 연결, 표시 형식, 견본 값, 번역 대상 아님, 미사용 문구 | O |
| `.../Review/Marks_<언어>.json` | 언어별 판정(OK/NG, 사유, 검수자, 시각) | O |
| `.../LocalizationQABindings.json` | 자동 검사(프리팹 검사)용 키 지정 | O |
| `LocalizationQA/` (프로젝트 루트) | 스크린샷, CSV | X |

판정 파일이 언어별로 나뉘어 있어 언어 담당자끼리 동시에 작업해도 병합 충돌이 적습니다.
작업 후에는 `Review/` 폴더를 커밋해 공유하세요.

## 8. 실제 게임과 같게 보이도록 하는 장치

툴은 프리팹을 프리뷰 씬에 띄워 그리므로, 게임 코드가 실행 중에만 바꾸는 부분은 다음처럼 맞춥니다.

- **언어별 폰트**: `LocalizationFontTable`과 같은 규칙으로 폰트를 바꿉니다.
- **레이아웃**: LayoutGroup·ContentSizeFitter를 다시 계산합니다.
- **연출로 숨겨진 팝업**: 투명도 0·크기 0에서 나타나는 패널은 연출이 끝난 상태로 보여줍니다.
- **화면 밖에서 들어오는 UI**: 칸이 캔버스 밖이면 화면 가운데로 옮겨 그립니다. (예: 던전 상태 배너)
- **스크롤 목록 안의 칸**: 칸이 목록의 보이는 영역 밖이면, 게임에서 그 항목으로 커서를 옮긴 것처럼 목록을 스크롤해 보여줍니다.
  Unity ScrollRect뿐 아니라 마스크(Mask·RectMask2D)로 잘라 보이는 영역이면 모두 해당합니다. (예: 옵션 창 아래쪽의 카메라 흔들림·데이터 동의 행 — 게임 자체 스크롤 `UI_CustomScroll`)
- **겹쳐 저장된 패널**: 그래도 글자가 가려지면, 그 위에 그려지는 다른 패널(겹친 탭 등)을 숨기고 그립니다.
- **앞 창이 열리면 감춰지는 창**: 칸이 앞 창 안에 있으면 게임이 감추는 뒤 창을 감춥니다. `LocQALayoutHooks.CoverRules`에 등록합니다.
  (예: ESC 화면에서 옵션 창 문구를 볼 때 ESC 메뉴는 감춤 — 게임은 옵션을 열 때 ESC 메뉴를 닫힘 연출로 지웁니다)
- **주변 칸의 문구**: 검수 중인 칸 말고 나머지 칸도 게임처럼 채웁니다. 순서대로
  ① 그 자리에 연결된 문구(여러 개면 프리팹에 적힌 문구와 같은 것) ② 프리팹 문구로 찾은 키
  ③ 그 칸에 연결된 문구가 하나뿐이면 그것 ④ 행 이름과 키가 맞는 것(OPT_WindowMode ↔ WindowMode) ⑤ 없으면 프리팹 문구 그대로.
- **코드가 크기·연출을 맞추는 UI**: 게임 코드의 그 메서드를 그대로 실행합니다.
  `LocQAResolution.cs`의 `LocQALayoutHooks`에 등록되어 있습니다.

| 등록된 훅 | 이유 |
|---|---|
| `UI_InitialSetupPopup.SnapConsentTogglesPixelPerfect` | 동의 토글 크기를 문구 길이로 맞춤 |
| `UI_TentAbilityComponent.BeginCircleReveal` → `EndCircleRevealImmediately` | 특성 화면의 원형 등장 연출 가림막을 걷어냄 |

**새 UI를 만들 때**: 문구 길이로 크기를 코드에서 직접 맞추거나, 등장 연출용 가림막이 프리팹에 켜진 채 저장되어 있다면
툴 화면이 게임과 달라집니다. 그 메서드(런타임 서비스에 의존하지 않는 것)를 `LocQALayoutHooks`에 한 줄 추가하세요.
한 창을 열 때 다른 창을 코드로 숨긴다면 `CoverRules`에 (앞 창, 뒤 창) 한 줄을 추가하세요.

**행 프리팹의 임시 문구에 주의**: 같은 행 프리팹(OPT_Selector 등)을 복사해 만든 행은 다른 행의 임시 문구("FPS", "Master Volume")가
그대로 남아 있는 경우가 많습니다. 툴은 연결된 문구를 우선하므로 그림은 맞게 나오지만, 새 행을 만들면 `이 칸에 문구 추가…`로
그 행의 실제 키를 연결해 주세요.

## 9. 자주 묻는 것

**Q. 그림이 "그리는 중…"에서 안 바뀌어요.**
Unity 창을 한 번 클릭해 포커스를 주세요. 언어별 검수는 에디터가 쉬는 동안 조금씩 그리므로 Unity가 백그라운드면 느려집니다.

**Q. "화면 프리팹에서 텍스트 칸을 찾지 못했습니다"가 나와요.**
프리팹 구조가 바뀐 것입니다. `목록 갱신`을 누르세요. 그래도 남으면 그 항목을 `목록에서 빼기` 하고 다시 연결합니다.

**Q. 자동 검사는 칸 초과라는데 그림은 멀쩡해요.**
판정은 사람이 합니다. 자동 검사는 참고용입니다. 그림이 정상이면 OK를 찍으세요.

**Q. 플레이 검사 스크린샷이 안 찍혀요.**
Game 뷰가 화면에 보이는 상태여야 합니다. Game 뷰 탭을 앞으로 꺼내 두세요.

**Q. Game 뷰 해상도 목록에 "LocQA 1920x1080" 같은 항목이 생겼어요.**
해상도를 바꿔 가며 검사(`모든 해상도 × 언어 순회`, Game 뷰 해상도 선택)할 때 툴이 만든 항목입니다.
순회가 끝나면 원래 크기로 되돌리지만, Unity가 제공하는 방법으로는 "LocQA …" 이름의 항목으로만 되돌릴 수 있습니다.
원래 쓰던 항목(Free Aspect 등)은 Game 뷰 해상도 드롭다운에서 다시 고르고, 남은 "LocQA …" 항목은 같은 목록에서 지우면 됩니다.

**Q. 플레이를 끝냈는데 Game 뷰에 박스가 남아 있어요.**
문제 위치 표시용 오버레이가 남은 것입니다. 현재 버전은 플레이 종료 때 자동으로 지우고, 에디터로 돌아올 때 남은 것도 정리합니다.
그래도 보이면 플레이를 한 번 시작했다가 끄면 정리됩니다.
