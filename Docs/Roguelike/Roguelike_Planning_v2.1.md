# 📖 1. 비전과 설계 원칙

> 💡 **이 모드를 왜 플레이 하는가?** 능력이 궁금해서, MAX와 히든 조합이 궁금해서, 내 빌드가 몇 웨이브까지 가는지 알고 싶어서 다시 한다.

> 🔁 **재플레이 동기**
> - 학살의 재미
> - 로그라이크에서 얻는 능력이 궁금해서 다시 한다
> - 특성(카드) 1개를 MAX 찍었을 때의 능력이 궁금하다
> - 특성(카드) 2개를 MAX 찍었을 때의 히든 특성이 궁금하다
> - 내 빌드가 **몇 웨이브까지 버티는지** 알고 싶다

> 📐 **설계 원칙**
> - 한 판은 **특정 카드 하나의 빌드**로 가도록 유도한다
> - 모든 카드를 만족시키는 범용 빌드는 만들지 않는다 (다회차 유도를 막기 때문)
> - 빌드 성공을 **보장하지 않는다** (로그라이크의 본질)
> - 히든 조합은 **완전 비공개**
> - 판을 넘어 이어지는 성장 요소는 **없다**

> 🧭 **난이도 설계 목표** (수치 근거는 부록 A)
> - 카드 없이 도끼만 쓰면 1~2웨이브까지만 여유롭고, 도끼만 풀업(액티브 없음)해도 2티어까지가 한계다
> - 3티어부터 도끼만으로는 터무니없이 힘들다
> - 4티어는 액티브 1개를 MAX로 만든 것만으로는 깰 수 없고, **22웨이브까지 만든 빌드에 4티어 구매를 이어 두 번째 액티브까지 키워야 겨우** 따라간다. 빌드가 잘 맞으면 학살의 재미를 느낀다

# 🔁 2. 한 판의 흐름

> 💡 **카드 선택 → 웨이브 전투 → 웨이브 클리어 → 다음 웨이브**를 30번 반복한다. 30웨이브를 클리어하면 언리밋 모드로 이어진다.

> 1️⃣ **카드 선택**
> 웨이브 시작 전, 시간이 멈춘 상태에서 카드 3장 중 1장을 골드로 구매한다. 마음에 들지 않으면 전체 리롤한다. 첫 웨이브만 무료 카드로 시작한다.

> 2️⃣ **웨이브 전투**
> 나무가 스폰되고 플레이어가 벤다. 나무가 임계치 이상인 상태가 일정 시간 유지되면 스태미너 피해를 받는다.

> 3️⃣ **웨이브 클리어**
> 목표 처치 수를 채우면 클리어. 나무는 묘목으로 돌아가 사라지고 코인은 한꺼번에 흡수된다.

> 4️⃣ **웨이브 전환**
> 다음 웨이브로 넘어가 1번으로 돌아간다. 티어 전환 웨이브는 지형 연출과 함께 상위 티어 나무가 등장한다.

> 🏆 **런 클리어**
> 30웨이브를 클리어하면 즉시 런 클리어, 곧바로 언리밋 모드(`Unlimit-1`~)로 이어진다.

> 💀 **게임오버**
> 스태미너가 0이 되면 패배한다. 언리밋 모드에서도 동일하다.

## 상태 흐름

```text
로비
  → 게임 시작(타격)
  → 런 시작 (골드 0)
  → [ 카드 선택 → (티어 전환 웨이브만) 지형 전환 연출 → 웨이브 전투 → 웨이브 클리어 ] × 30웨이브
  → 30웨이브 클리어 = 런 클리어 (기록 즉시 저장)
  → 언리밋 모드 (카드 없이 웨이브 전투만 반복)
  → 게임오버 또는 포기 → 결과 기록 → 결과 화면 → 확인 → 디스토션 → 진입 연출 → 로비
```

| 상태 | 진입 조건 | 이 상태에서 일어나는 일 | 다음 상태 |
|---|---|---|---|
| 🏠 **로비** | 진입 연출이 끝남 | 플레이어가 자유롭게 움직이고, 오브젝트를 타격해 상호작용한다 | 게임 시작 타격 → 런 시작 |
| 🏁 **런 시작** | 게임 시작 타격 | 골드 0, 보유 카드 없음, 리롤 비용 초기화 | 카드 선택 (웨이브 1, 무료 카드) |
| 🃏 **카드 선택** | 웨이브 시작 전 (첫 웨이브 포함) | 시간이 흐르지 않는다. 카드 3장 제시 → 구매 / 건너뛰기 / 리롤 | 티어 전환 웨이브면 지형 전환 연출, 아니면 웨이브 전투 |
| 🏔️ **지형 전환 연출** | 티어 전환 웨이브의 카드 선택 직후 | 지형 변경 연출, 상위 티어 나무로 교체. 웨이브는 진행되지 않은 상태로 대기 | 연출이 끝나면 웨이브 전투 |
| 🌲 **웨이브 전투** | 카드 선택 종료 (필요 시 지형 전환 연출 종료) | 나무 스폰·벌목, 코인이 바닥에 흩뿌려짐(알파 낮음), 임계치 유예·피해 판정 | 목표 처치 수 달성 → 웨이브 클리어 / 스태미너 0 → 게임오버 |
| ✅ **웨이브 클리어** | 목표 처치 수 달성 | 스폰 중지, 코인 알파 복구, 나무 묘목 복귀와 코인 흡수 동시 진행 | 웨이브 30 미만이면 카드 선택, 30이면 런 클리어 |
| 🏆 **런 클리어** | 30웨이브 클리어 | **기록 즉시 저장**, 마지막 나무 줌인 + 슬로우 부서짐 연출 후 줌아웃 | 언리밋 모드 |
| ♾️ **언리밋 모드** | 런 클리어 직후 | 카드 선택 없음, 골드 드롭·코인 HUD 숨김, 나무 스탯만 상승하며 `Unlimit-N` 웨이브 반복 | 스태미너 0 → 게임오버 / ESC 포기 → 결과 화면 → 로비 |
| 💀 **게임오버** | 스태미너 0 | 쓰러지는 애니메이션 재생 후 결과를 기록한다 (결과 화면 직전) | 결과 화면 |
| 📊 **결과 화면** | 게임오버 기록 직후 (또는 포기) | 도달 웨이브, 플레이 시간, 총 부순 나무, 총 획득 코인, 보유 카드(레벨 포함) 표시 | 확인 → 결과 화면에서 바로 디스토션 → 진입 연출 → 로비 |

> ⏸️ **ESC 포기 (어느 상태에서나)**: 런 도중 ESC → EscapeMenu → 포기 → 결과 화면 → 로비. 30웨이브 전 포기는 최근 기록에만 저장하고, 언리밋 중 포기는 마지막으로 클리어한 Unlimit 웨이브까지 기록한다.

# ⚔️ 3. 전투 규칙

## 3-1. 필드와 웨이브

| 항목 | 규칙 |
|---|---|
| 🌲 **필드** | 고정된 작은 영역이며 스폰 위치는 필드 내부로 제한한다. 필드 크기는 지정하지 않는다 |
| 🌲 **나무 등장** | 필드는 빈 채로 시작하고, 웨이브마다 정해진 속도로 나무가 **무조건 등장**한다. 임계치 T를 넘어 **추가 개수(+α, 10~15그루)까지** 계속 자라며, 이 상한이 **스폰 상한**(T + 추가 개수)이다 |
| 🌲 **상한 도달 후** | 리스폰이 멈추고, 나무가 한 그루 죽으면 **즉시 다시 스폰**된다 |
| ⏱️ **스폰 주기** | 웨이브마다 정해진 값. 스폰 상한과 독립 변수이며 부록 A에서 관리한다 |
| 🎯 **클리어 조건** | **목표 처치 수 달성**. 웨이브마다 목표 수가 정해져 있고, 채우는 속도가 곧 빌드의 화력 평가가 된다. **웨이브에 시간 제한은 없다** |
| 🛑 **달성 즉시** | 스폰을 중지하고, 필드의 나무가 **묘목으로 되돌아가며 사라지는 연출**이 재생된다 (모든 웨이브 공통). 남은 나무는 골드를 주지 않는다 |
| 🎥 **마지막 웨이브** | 줌인 + 슬로우 부서짐 연출은 **30웨이브 클리어 시에만** 재생한다 (7장 참고) |
| 🎮 **플레이어 조작** | 공격은 본 게임 숲 스테이지의 동작을 그대로 사용한다. 도끼는 기본적으로 **가장 가까운 나무 한 그루**를 친다 (단일 타격) |

## 3-2. 스태미너 (패배 조건)

> 💡 나무가 임계치 이상 **쌓인 채로 버티면** 피해를 입는다. 바로 피해를 입지 않는다. 유예 시간 동안 대응할 수 있다.

| 항목 | 규칙 |
|---|---|
| 📏 **임계치 T** | 기본값은 고정이며 인내의 시간 등으로 감소할 수 있다. 스폰 상한은 항상 **현재 임계치 + α(10~15그루)** |
| 🟡 **첫 피해** | 나무 수가 T 이상인 상태가 **유예 시간(N초)** 동안 유지되면 첫 피해를 입는다 |
| 🔴 **반복 피해** | 첫 피해 이후에도 T 이상이면 **피해 쿨다운(N초)마다** 계속 피해를 입는다 |
| ↩️ **초기화** | T 아래로 내려가면 **유예 타이머와 피해 쿨다운이 모두 초기화**된다. 다시 T 이상이 되면 이전 쿨다운과 상관없이 유예 타이머가 끝나는 즉시 첫 피해를 입는다 |
| 💥 **피해량** | **티어 스테이지마다 오른다** (값은 부록 A. 언리밋은 4티어와 동일) |
| 💀 **게임오버** | 스태미너가 0이 되면 게임오버 |
| 💚 **회복** | 웨이브 클리어 시 자동 회복되지 않고 유지된다. 회복은 카드(스태미너 회복)로 해결한다 |

> 📈 **압박이 생기는 방식**: 웨이브가 올라갈수록 나무 HP가 구간마다 단계적으로 오르고 초당 스폰도 늘어 처치 속도가 모자라지기 쉬워진다. 티어 스테이지마다 피해량이 커져 한 번의 피해가 무거워진다.

### 피해 판정 흐름

| 상태 | 조건 | 동작 |
|---|---|---|
| 🟢 **안전** | 나무 수가 T 미만 | 피해 없음. 유예 타이머는 초기 상태 |
| 🟡 **유예 중** | 나무 수가 T 이상이 됨 | 유예 타이머 진행. N초 안에 T 미만으로 내리면 초기화되고 안전으로 복귀 |
| 🟠 **첫 피해** | 유예 타이머 완료 | 스태미너 피해 1회 |
| 🔴 **지속 피해** | 첫 피해 이후에도 T 이상 유지 | 피해 쿨다운마다 반복 피해 |
| ↩️ **복귀** | 지속 피해 중 T 미만으로 하락 | 안전으로 복귀. 유예 타이머와 쿨다운이 모두 초기화되고, 다시 T 이상이 되면 유예 중부터 다시 시작 |

# 🛒 4. 골드와 카드 선택

> 💡 **핵심 선택**: "지금 나온 카드를 살 것인가, 골드를 써서 교체할 것인가". 횟수 제한 대신 **비용 상승**으로 자유와 긴장을 동시에 확보한다.

## 4-1. 선택 단계 규칙

| 항목 | 규칙 |
|---|---|
| 🃏 **제시** | 웨이브 전투 시작 전, 시간이 흐르지 않는다. 카드 **N장**(현재 3장, 카드 수가 늘면 5장·8장으로 조정 가능)을 제시한다 |
| 💰 **구매** | 골드를 지불해 카드 1장을 구매하면 전투가 시작된다. 골드는 카드 구매와 리롤에 쓰는 **단일 재화**다 |
| ⏭️ **건너뛰기** | 구매하지 않고 건너뛰어도 된다. 골드를 모아 두는 전략이 가능하다 |
| 🔄 **리롤** | 골드를 지불하고 **전체 교체**. 횟수 제한 없음. 사용할 때마다 비용이 상승하고 **한 판 내내 유지**, 새 런에서 초기화 |
| 🎁 **첫 선택** | 런 시작 시 골드 0. 웨이브 1에서 바로 카드 1장을 선택하며 **무료**, **액티브 7종 중에서**(등급 무관) 제시, **무료 리롤 1회** 제공 (원하는 카드가 안 나오면 한 번 교체할 수 있다. 이 리롤은 리롤 비용 상승 횟수에 포함하지 않는다) |
| 💲 **가격** | 등급에 따라 다르다. 약한 카드는 싸고 희귀 카드는 비싸다 (5장 카드 시스템, 부록 A) |

## 4-2. 골드(코인) 획득

| 단계 | 내용 |
|---|---|
| 1️⃣ **벌목** | 나무를 베면 코인이 **땅에 흩뿌려진다**. 떨어지는 즉시 흡수되지 않는다 |
| 2️⃣ **전투 중** | 바닥 코인은 **알파 값을 낮춰 거의 보이지 않게** 한다 |
| 3️⃣ **웨이브 종료** | 알파 값을 **원래대로 복구**한 뒤 흡수 연출로 이어진다 |
| 4️⃣ **흡수** | 흩뿌려진 코인이 **자동으로 한꺼번에 드르르륵** 흡수된다. 나무가 묘목으로 돌아가는 연출과 **동시에** 진행되며, 이후 카드 선택으로 넘어간다 |
| 5️⃣ **표시** | 코인 HUD 쪽으로 날아가는 애니메이션과 함께 보유 골드가 오른다 |

## 4-3. 카드 노출 규칙

> 📌 에메랄드·프리즘 조건이 충족되면 **무조건 다음 선택에 노출**하고, 조건이 유지되는 동안 **매 선택마다 계속 노출**한다. 구매하지 않고 건너뛰어도 다음 선택에 다시 나온다. 에메랄드·프리즘 카드는 **무료**이므로 골드가 부족해도 항상 선택할 수 있다.

| 순서 | 규칙 | 설명 |
|---|---|---|
| **0 제외** | 배타 그룹·MAX·보유 루비 제외 | **가장 먼저** 적용한다. 제외된 카드가 보장 노출에 걸려 다시 나오는 일은 없다 |
| **슬롯 1** | 보장 노출 카드 | 에메랄드·프리즘 조건 충족 카드를 한 번에 **1~2장까지** 노출, 나머지는 **다음 선택으로 이월** (카드 수가 늘면 조정). 3장 중 최대 2장까지만 쓰고 1장 이상은 일반 카드로 남긴다. 프리즘이 에메랄드보다 우선이고, 같은 종류 안에서는 먼저 쌓인 카드가 먼저 나온다. 서로 배타인 프리즘이 여러 장 대기 중이면 전부 함께 노출한다 (최대 3장, 슬롯 상한의 예외) |
| **슬롯 2** | 액티브 카드 1장 보장 | 선택할 때마다 3장 중 **액티브를 최소 1장** 넣는다. 후보는 미보유 액티브와 보유 중이지만 MAX가 아닌 액티브(배타 그룹 제외)이고, 고르는 방식은 일반 가중치를 그대로 쓴다. 액티브가 실버라 등급 비중만으로는 브론즈 패시브보다 덜 나오기 때문에 두는 규칙이다. 가격과 무관하게 넣으므로 골드가 부족해도 노출되고, 모아야 할 목표를 보여 주는 역할도 한다. **보유 액티브가 3장 이상이면 해제**하고, 후보가 없을 때도 해제한다. 슬롯 1이 3장을 모두 차지하는 경우(배타 프리즘 예외)에는 그 선택에서만 건너뛴다 |
| **슬롯 3** | 구매 가능 카드 2장 이상 보장 | 카드 1장씩 단독 기준. 합계·리롤 비용은 고려하지 않는다. **슬롯 2의 액티브가 구매 가능하면** 그 액티브를 구매 가능 카드 1장으로 세고 남은 자리에서 1장만 더 구매 가능한 카드로 채운다. **구매 불가이면** 나머지 두 장을 모두 **구매 가능한 브론즈 카드**로 채운다. 무료인 슬롯 1의 에메랄드·프리즘은 구매 가능으로 세어 그만큼 채우는 수를 줄인다. 구매 가능한 브론즈 카드가 모자라면 구매 가능한 다른 등급 카드로 채우고, 그래도 모자라면 아래 카드 풀 예외 처리를 따른다 |
| **가중 1** | 업그레이드 우선 | 이미 보유한 카드의 **다음 레벨 카드**가 더 자주 노출된다 |
| **가중 2** | 조합 파트너 유도 | 조합에 필요한 카드 중 한 장이 **II 레벨 이상**이면 유도를 시작하고, **MAX**가 되면 파트너를 확실히 노출한다. 비중에는 상한이 있다 (유저에게 비노출) |
| **가중 3** | 등급 비중 | 브론즈 > 실버 > 골드 > 루비 순으로 노출 비중을 낮춘다. 노출 추첨 가중치는 `등급 비중 × 업그레이드 우선 × 조합 파트너 유도`다 |
| **안전망** | 편향 상한 | 한 방향으로 완전히 고착되는 것을 막는다 |
| **리롤** | 동일 규칙 | 리롤은 **모든 카드를 교체**한다. 위 규칙(제외 → 슬롯 1~3 → 가중치)을 그대로 적용한다. 아직 노출되지 않은 보장 대기 카드가 있으면 그 카드를 우선 노출한다. 대기 카드가 모두 이미 노출된 상태에서 리롤하면, 노출됐던 보장 카드는 카드마다 50% 확률로 다시 노출된다 (다시 나오지 않은 카드는 다음 선택에 다시 노출된다) |
| **빌드 보장** | 없음 | 운이 나쁘면 원하는 빌드가 나오지 않을 수 있다 (로그라이크의 본질) |

### 구매 불능 방지

> 🛡️ 골드가 부족해 **아무 카드도 살 수 없는 상황**을 시스템이 막는다.
> - 제시되는 3장 중 **보유 골드로 단독 구매 가능한 카드가 2장 이상** 나오도록 내부에서 유도한다 (위 표의 슬롯 3)
> - 리롤로 새로 뽑을 때도 동일하게 적용하며, 보장 노출 카드와 액티브 보장 다음 순위이고 노출 가중치보다 우선한다
> - **밸런스 목표**: 매 웨이브가 끝나면 단독 구매 가능한 카드가 2개 이상 되도록 골드 수급량을 조정한다
> - 제거되는 나무는 골드를 주지 않으므로, 수급은 처치 수를 채우는 과정의 드롭만으로 충족해야 한다

### 카드 풀 예외 처리

| 상황 | 규칙 |
|---|---|
| 📉 **노출 가능한 카드가 3장 미만** | 있는 만큼만 제시한다 (1~2장). MAX 카드나 보유한 루비를 다시 넣어 3장을 채우지 않는다 |
| 🚫 **노출 가능한 카드가 0장** | 선택 화면에 **"지금은 구매할 수 있는 카드가 없습니다"** 안내 연출을 재생하고, 연출이 끝나면 확인 입력 없이 웨이브가 시작된다. 조용히 넘기지 않는다 |
| 💸 **제시된 카드가 모두 골드 부족** | 모든 가격을 붉게 표시하고 **"골드가 부족합니다"** 안내를 띄운다. 건너뛰기를 누르면 웨이브가 시작된다. 감정은 보유 골드가 감정비 이상일 때만 쓸 수 있고, 아니면 감정 버튼이 잠긴다 |
| 🔢 **구매 가능한 카드가 2장 미만 (보장 불가)** | 풀에 있는 구매 가능 카드를 모두 포함하고, 나머지 자리는 일반 추첨으로 채운다. 골드가 부족한 카드는 붉은 가격으로 표시한다 |
| 🔁 **같은 카드가 한 선택에 두 번 필요** | 넣지 않는다 (같은 카드는 한 선택에 한 번만 노출) |

> 🔒 **히든 조합**: 카드 두 장을 MAX로 만들면 조합 카드(프리즘)가 열린다. 조합 정보는 게임 내 어떤 UI에도 **사전 노출하지 않는다** (뱀파이어 서바이버, 로켓래츠와 같은 방식).

## 4-4. 카드 감정 (한 판 한 번의 도박)

> 🔍 **이판사판 도박 시스템**: 보유한 카드를 골드를 내고 감정에 맡겨 레벨을 올리는 도박이다. 포켓몬 카드 그레이딩에서 아이디어를 얻었다.
> - **한 판에 딱 한 번**, 웨이브 10~20 중 무작위로 정해진 웨이브의 카드 선택 단계에 감정사가 등장한다. 웨이브 10에 진입할 때 감정사가 숲을 찾아온다는 예고가 표시된다 (실제 등장 웨이브는 알려주지 않는다)
> - 보유한 **레벨 I~IV 카드**(액티브·공통 패시브)를 **최대 3장**까지 감정할 수 있다. 서로 다른 카드여야 하며 같은 카드를 반복해서 맡길 수 없다. 골드가 허락하는 만큼 맡길 수 있다. MAX 카드·루비·프리즘은 대상이 아니다
> - 새로 구매할 카드는 감정할 수 없다. 감정은 **선택 기회를 소모하지 않고**, 카드 구매와 함께 할 수 있다
> - 결과 레벨이 현재 레벨보다 **낮거나 같으면 현재 레벨을 유지**하고, **높으면 즉시 그 레벨로 승격**한다. 하락은 없다. 위험은 감정비를 날리는 것뿐이다
> - 결과는 **비용을 낸 시점에 확정**되고, 스티커를 뜯는 조작은 결과를 확인하는 연출이다 (속도·거리가 결과에 영향을 주지 않는다)
> - 평균적으로는 골드 기준 약간 손해다. +1은 살짝 손해, +2는 확실한 이득, MAX는 큰 이득이다

| 보유 레벨 | 브론즈 감정비 | 실버 감정비 | 골드 감정비 | 결과 분포 (유지 / +1 / +2 / MAX) |
|---|---|---|---|---|
| **I** | 90 | 224 | 449 | 55% / 25% / 15% / 5% (평균 약 −24%) |
| **II** | 110 | 276 | 552 | 50% / 25% / 17% / 8% (평균 약 −18%) |
| **III** | 138 | 345 | 690 | 45% / 28% / — / 27% (+2와 MAX는 같은 결과, 평균 약 −23%) |
| **IV (MAX 도전)** | 66 | 165 | 330 | 65% / — / — / 35% (평균 약 −20%) |

> 💰 **감정비 공식**: 레벨 I~III은 `다음 레벨 정가 × 1.15`, IV는 올라갈 곳이 MAX 하나라 `기준 가격 × 1.1`. 가격 정책 루비(바겐 세일!, VIP 회원권)의 영향을 받지 않는다. 수치는 밸런스 단계에서 조정한다.

> ✅ **확정: 골드 부족 시 감정 버튼 잠금**
> - 감정사가 등장했을 때 **감정 UI 버튼을 잠금 처리**한다. 감정할 수 있는 카드(레벨 I~IV 보유)가 없거나 보유 골드가 가장 싼 감정비보다 적으면 버튼을 비활성(잠금 표시)으로 둔다
> - 구매·리롤·건너뛰기 등 나머지 선택 조작은 그대로 쓸 수 있다
> - 잠긴 채로 그 선택 단계가 끝나면 **감정 기회는 사라지며 다음 선택으로 이월하지 않는다**

# 🃏 5. 카드 시스템

> 📚 이 장은 카드 **전체에 공통으로 적용되는 규칙**이다. 카드 한 장 한 장의 내용(효과·등급·설명 문구)은 6장 카드 도감, 수치와 가격표는 부록 A를 본다.

## 5-1. 카드 종류와 태그

| 종류 | 설명 | 구성 |
|---|---|---|
| ⚔️ **액티브** | 플레이어가 스킬로 사용하는 카드. 구매하면 **자동으로 발동**한다 (입력으로 사용하지 않는다) | 오프로드, 회전베기, 충격파, 드론, 부메랑, 스텔라, 포자폭탄 (7종) |
| 💎 **조합(프리즘)** | 두 액티브를 모두 MAX로 만들면 열리는 히든 카드. 자동 부여되는 등급이며 무료다 | 5종 |
| 🔧 **공통 패시브** | 플레이어 전체(기본 무기 도끼와 모든 액티브 포함)에 적용되는 패시브. **액티브 전용 패시브는 두지 않는다.** 태그가 없다 | 공격력, 공격속도, 범위 등 (11종) |
| 🪓 **기본 무기(도끼)** | 플레이어가 처음부터 들고 시작하는 무기. **카드가 아니다.** 도끼 강화는 공통 패시브(전체 공격력 증가 등)로 처리한다 | 본 게임 숲 스테이지의 기본 공격 동작 |
| ❤️ **루비** | 버프와 디메리트를 함께 가진 카드. 업그레이드가 없다 | 5종 |

| 태그 규칙 | 내용 |
|---|---|
| 🏷️ **내부 태그** | 액티브 카드는 그 스킬을 가리키는 태그(예: `Shockwave`)를 갖는다. 패시브는 전체에 적용되므로 태그가 없다 |
| 🏷️ **이름과 별개** | 카드 이름은 자유롭게 짓고 이름에 스킬 이름을 넣지 않는다 (넣으면 폭이 좁아지기 때문). 시스템은 내부 태그로만 카드를 찾는다 |
| 🏷️ **용도** | 태그는 시너지 판단이 아니라 카드를 식별하는 용도로만 쓴다 (태그 비율 가중치는 쓰지 않는다) |

> 🧬 **카드 효과의 범위**: 카드는 플레이어 스탯·스킬뿐 아니라 **게임 루프 값**(예: 나무 생성률)에도 영향을 줄 수 있다. 루비 카드의 디메리트가 대표적인 예다.

> ⚠️ **구현 시 주의: 런 단위 스킬 부여**
> - 액티브 카드의 스킬은 **런 단위로 부여·해제**되어야 한다
> - 본 게임의 스킬은 **영구 능력 트리(세이브)에 묶여** 있어서, 런의 카드 효과가 영구 진행 데이터에 영향을 주지 않도록 주의한다
> - 런이 끝나면 판 안의 카드·스킬 상태는 모두 사라져야 한다 (로그라이트 요소 없음)

## 5-2. 카드 레벨

| 항목 | 규칙 |
|---|---|
| ⬆️ **업그레이드** | 같은 카드를 다시 구매하면 레벨이 오른다. 처음 구매하는 카드와 업그레이드 중인 카드를 구분해 제시한다 |
| 🔢 **표기** | 카드 이미지 아래에 `I`, `II`, `III`, `IV`, `MAX`(5레벨)로 표기한다. **구매 후 레벨**이다 (처음 구매는 `I`) |
| 🏁 **MAX** | 더 이상 올라가지 않는다. MAX가 되는 구매 카드는 **에메랄드 등급**으로 표기하며 **가격 없이 무료**로 제공한다 (선택 기회는 소모) |
| 📏 **레벨 상한** | **모든 카드 최대 5레벨로 통일**한다. 5레벨이 `MAX`로 표기된다. 루비는 레벨이 없다. 조합 1장을 완성하는 데 필요한 구매는 재료 2장 × (유료 I~IV 4회 + MAX 무료 1회) + 프리즘 1회 = 11회다 |
| 📚 **보유 제한** | 보유할 수 있는 카드 종류 수에 제한은 없다. 한정된 골드와 30웨이브 안에서 전략적으로 구성한다 (밸런스) |

## 5-3. 카드 등급과 가격

| 등급 | 의미 | 지정 방식 | 비고 |
|---|---|---|---|
| 🥉 **브론즈** | 기본 등급 카드 | 개발자 지정 | 첫 구매 가격 **100 이내** (업그레이드 제외) |
| 🥈 **실버** | 높은 등급이라고 판단되는 카드 | 개발자 지정 | 첫 구매 가격은 등급별 단가 |
| 🥇 **골드** | 더 높은 등급이라고 판단되는 카드 | 개발자 지정 | 첫 구매 가격은 등급별 단가 |
| 💚 **에메랄드** | 사면 해당 카드가 **MAX 레벨**이 되는 카드 | 동적 (자동) | 실버·골드도 MAX 직전 업그레이드면 에메랄드로 표기. **가격 0(무료)** |
| 💎 **프리즘** | 두 카드가 MAX가 되어 **조합 가능해진 조합 카드** | 동적 (자동) | 히든 조합 카드. 한 카드가 여러 조합의 재료로 쓰일 수 있고, 재료 카드는 조합 후에도 그대로 유지된다. 단 재료가 겹치는 조합은 한 판에 하나만 만들 수 있다. 재료 카드의 기존 능력 사용 여부는 **조합마다 다르게 정한다**. **무료**로 제공한다 |
| ❤️ **루비** | 강한 효과와 **디버프**를 함께 가진 카드 | 개발자 지정 | **업그레이드가 없다.** 레벨 대신 `±` 표기 |

> 🏷️ **지정 기준**: 브론즈는 단순하고 어느 빌드에서나 즉시 체감되는 카드, 실버는 빌드 방향을 정하거나 특정 상황에서 효과가 큰 카드, 골드는 판의 규칙을 크게 건드리거나 시스템이 복잡한 카드다. 에메랄드와 프리즘은 자동 부여되어 지정하지 않는다.
> - **액티브 7종은 모두 실버로 둔다**: 가격(기준 150, MAX까지 885)으로 한 판에 살 수 있는 액티브 수를 골드가 제한하게 하려는 것이며, 4티어 난이도 목표(22웨이브까지 만든 빌드로 시작해 4티어 구매를 이어야 겨우 클리어)의 전제다. 스텔라는 복잡도 기준으로는 골드지만 이 목적이 우선해 실버로 둔다
> - 핵심 딜 패시브(공격력·공격속도·범위)는 브론즈(MAX까지 354)로 둔다
> - 골드 획득 증가는 "모든 레벨이 본전 이상" 규칙을 지키기 위해 브론즈로 둔다 (부록 A)
> - 각 카드의 지정 등급은 6장 카드 도감의 표가 기준이다

| 가격 규칙 | 내용 |
|---|---|
| 💰 **첫 구매** | **기준 가격 P**(브론즈 레벨 I = 60골드) × **등급 비율** (브론즈 1 / 실버 2.5 / 골드 5 / 루비 4, 프리즘은 무료) |
| 💰 **업그레이드** | 해당 카드의 레벨마다 **그 카드에 한해** 단계적으로 오른다. **레벨 배율**은 I 1.0 / II 1.3 / III 1.6 / IV 2.0 / V(MAX) 무료 (예: 1~4레벨 카드면 그 카드의 가격만 레벨별로 오름) |
| ❤️ **루비** | 단점(디메리트)을 감수하는 대신 추가 버프를 제공한다. 루비는 5종으로 확정한다. 업그레이드가 없으므로 에메랄드와 등급이 겹치지 않는다 |
| 📋 **가격표** | 등급 × 레벨 가격표는 부록 A에 있다 |

> 📊 **등급별 노출 비중**: 브론즈 > 실버 > 골드 > 루비 순으로 노출 비중을 낮춘다 (수치는 밸런스). 액티브가 실버라 덜 나오는 문제는 4장의 액티브 보장(슬롯 2)이 메운다. **런 시작 무료 카드**는 등급과 무관하게 **액티브 7종 중에서** 제시한다 (액티브가 실버라 첫 골드로는 살 수 없으므로, 첫 카드로 액티브를 얻게 한다).

## 5-4. 배타 그룹 (동시에 가질 수 없는 카드)

> 🚫 일부 카드는 서로 효과가 상충해 한 판에 동시에 가질 수 없다. 카드마다 `배타 그룹` 값을 지정하고, **같은 값을 가진 카드는 한 장만 구매**할 수 있다. 그룹에 속한 카드 수는 2장 이상도 가능하다.

| 규칙 | 내용 |
|---|---|
| ✅ **구매 시 제외** | 그룹 안의 카드를 한 장 구매하면, 그 런에서 같은 그룹의 나머지 카드는 **제시 풀에서 빠진다**. 구매 직후 전투가 시작되므로 다음 선택부터 적용된다 |
| 👀 **동시 노출** | 같은 그룹의 카드가 **한 선택에 함께 나올 수 있다**. 이때는 "둘 중 하나"를 고르는 양자택일이 된다. 하나를 구매하면 함께 제시되어 있던 상충 카드는 **소멸 연출**과 함께 사라진다 (10장) |
| 🔢 **적용 순서** | 배타 그룹 제외를 **가장 먼저** 적용한 뒤 보장 노출, 액티브 보장, 구매 가능 카드 보장, 노출 가중치를 순서대로 적용한다. 제외된 카드가 보장 노출에 걸려 다시 나오는 일은 없다 |
| 🔄 **리롤** | 리롤로 뽑는 카드에도 같은 제외를 적용한다 |
| 🔒 **비공개** | 다음 선택부터 제외되는 카드는 따로 알리지 않고 조용히 빠진다. 같은 선택에 함께 있던 상충 카드만 소멸 연출로 사라지는 것을 보여 준다. 필요하면 카드 설명에 같은 계열의 카드와 함께 가질 수 없다는 문구를 넣는다 |
| ⚠️ **조합 재료 주의** | 조합 재료 카드를 배타 그룹에 넣지 않는다. 다른 카드를 구매하는 순간 조합이 막히는 상황을 방지한다 |

| 배타 그룹 | 속한 카드 | 상충 이유 |
|---|---|---|
| 💸 **가격 정책** | 바겐 세일!, VIP 회원권 | 카드 가격 반값 / 대폭 증가와 리롤 불가 / 리롤 무료가 서로 상충 |
| ⭐ **스텔라 조합** | 스텔라 + 포자폭탄, 스텔라 + 드론 (조합 카드) | 별을 다루는 방식(도끼로 치는 반응 / 별 사이 빔과 노바)이 서로 충돌해 한 판에 한 장만 가질 수 있다. 한 장을 구매하면 다른 한 장은 더 이상 나오지 않는다 |
| 🔺 **삼각 조합** | 회전베기 + 충격파, 부메랑 + 충격파, 회전베기 + 부메랑 (조합 카드) | 재료가 겹치고 재료 능력 처리가 서로 충돌하므로 한 판에 한 장만 가질 수 있다 |

## 5-5. 카드 효과 적용 시점

> ⚡ 카드 효과는 **구매 즉시 적용**되고, 바로 이어지는 웨이브의 전투 시작부터 반영된다. 웨이브 도중에는 카드를 구매할 수 없으므로 전투 중에 효과가 바뀌는 일은 없다. 감정으로 레벨이 오르는 경우도 선택 단계에서 즉시 적용된다.

| 카드 | 적용 방식 |
|---|---|
| ⚔️ **액티브(처음 구매)** | 구매 즉시 활성화되고, 웨이브 시작 후 첫 발동 주기부터 작동한다 |
| ⬆️ **레벨 업** | 구매 즉시 새 레벨 효과로 바뀌고 이번 웨이브부터 반영된다 |
| 💪 **공격력·범위·공격속도·이동속도·지속 피해·유지 시간** | 즉시 적용 (이미 활성 상태인 스킬은 다음 발동부터 반영) |
| ❤️‍🩹 **최대 스태미너 증가** | 최대치와 현재 스태미너가 **즉시 함께 증가**한다 |
| 🩹 **스태미너 회복** | 구매 직후 회복은 없다. **다음 웨이브 클리어 시점**부터 회복한다 |
| 🕐 **유예 시간·피해 쿨다운 증가** | 즉시 적용 (이번 웨이브의 임계치 판정부터) |
| 🪙 **골드 획득 증가** | 이번 웨이브에서 떨어지는 코인부터 적용한다 |
| 💥 **루비: 유리 대포** | 최대 스태미너가 즉시 감소하고, 현재 스태미너는 새 최대치를 넘지 않도록 조정한다 |
| ⏳ **루비: 인내의 시간** | 임계치와 스폰 상한이 즉시 바뀌고 이번 웨이브부터 적용된다 |
| ➕ **루비: 다다익선** | 이번 웨이브부터 발동 수가 늘고 나무 스폰도 빨라진다 |
| 💸 **루비: 바겐 세일!·VIP 회원권** | 구매한 순간이 아니라 **다음 선택부터** 가격이 바뀐다. 이 카드 자체의 구매 가격에는 적용하지 않는다 |
| 💎 **조합 카드(프리즘)** | 구매 즉시 효과가 적용된다. 재료 기존 능력 처리는 조합별 규칙을 따른다 |

## 5-6. 카드 이름과 설명 작성 규칙

> ✍️ - 이름은 루비 카드를 제외하고 원 이름 그대로 쓴다. 조합 카드는 재료 이름을 `A + B`로 이어 쓴다
> - 설명은 상황 묘사가 아니라 **효과**를 한 줄로 쓴다. 세부 동작과 예외는 설명에 넣지 않고 기획서의 레벨 효과 표와 비고에서 관리한다
> - 도끼의 공격 동작은 항상 `도끼 공격`으로 쓴다 (예: 도끼 공격과 모든 스킬의 범위)
> - 일부 대상에만 적용되는 효과는 "일부"로 묶어 간결하게 쓴다
> - 용어: 지속 피해(도트 대신), 유지 시간(시간만), 지속형 스킬(남아 있는 스킬)

# 📚 6. 카드 도감

> 📖 카드 28종의 **효과 · 등급 · 카드에 표시되는 설명 문구**를 한곳에 모았다. 등급은 이 장의 표가 기준이다. 레벨별 수치와 가격은 부록 A를 본다.

## 6-1. 액티브 7종

> 📌 **패시브는 공통 패시브만 존재한다.** 액티브 전용 패시브는 두지 않는다. 액티브 스킬로 죽은 나무(지속 피해 포함)는 **모두 처치 수와 골드 드롭에 포함**한다.

| 액티브 카드 | 등급 | 발동 방식 | 조합 | 설명 문구 |
|---|---|---|---|---|
| 🚙 **오프로드** | 🥈 실버 | 본편 오프로드 비주얼을 그대로 사용한다. 필드 끝 면 타일 위에 랜덤하게 플래시되며 소환되고, 끝 면에서 정면 방향으로 돌진하며 나무를 빠르게 치고 간다 | 없음 | 일정 주기마다 오프로드 차량이 돌진해 지나간 나무에 피해를 준다. |
| 🌀 **회전베기** | 🥈 실버 | 본편 특성과 동일한 조건. 도끼를 n번 휘두를 때마다 회전베기를 한다 | 충격파, 부메랑 | 도끼로 n번 공격할 때마다 회전베기가 발동한다. |
| 💥 **충격파** | 🥈 실버 | 본편과 동일한 발동 조건 (도끼를 휘두를 때 확률 판정) | 회전베기, 부메랑 | 도끼로 공격하면 일정 확률로 공격 방향 뒤쪽에 충격파가 발동한다. |
| 🚁 **드론** | 🥈 실버 | 본편 드론과 동일. 주변 나무에 레이저를 발사하며, 3레벨부터 체인 라이트닝처럼 연쇄된다 | 스텔라 | 드론이 일정 주기마다 주변 나무에 레이저를 발사한다. |
| 🪃 **부메랑** | 🥈 실버 | 플레이어에게 돌아오자마자 즉시 다시 발사되는 **상시 발사** 방식. 왕복하는 동안 경로 위의 나무에 틱 피해를 준다 | 충격파, 회전베기 | 부메랑이 왕복하며 범위 내 나무에 지속적으로 피해를 준다. |
| ⭐ **스텔라** | 🥈 실버 | 본편 3스테이지의 별 표식 나무에서 나오는 별을 활용한다. 아무 나무나 베면 랜덤 확률(처음에는 낮음)로 벤 위치에 별이 소환된다. 별은 기본적으로 도끼로만 칠 수 있고, 공격받으면 주변 일대를 **단발성으로 공격하고 별 표식을 남긴다**. 별 표식이 남은 나무는 표식이 유지되는 동안 **받는 피해가 30% 증가**한다 (기본 효과). 다른 액티브가 별을 칠 수 있게 하는 것은 **스텔라 레벨 III 효과**로 개방한다 | 포자폭탄, 드론 | 나무를 벨 때 일정 확률로 별이 생긴다. 별을 공격하면 폭발하며 별 표식을 남긴다. 표식이 남은 나무는 받는 피해가 증가한다. |
| 💣 **포자폭탄** | 🥈 실버 | 자동으로 특정 위치에 포자 폭탄을 던진다. 그 위치에 n초 동안 지속 피해를 입히는 연막이 형성된다. 지속 피해로 죽은 나무도 처치 수와 골드 드롭에 포함된다 | 스텔라 | 일정 주기마다 포자 폭탄을 던져 연막을 만든다. 연막 안의 나무는 지속 피해를 받는다. |

### 액티브 레벨별 효과 (1~5레벨)

> 📌 레벨 효과는 누적 적용되며 5레벨(MAX)은 질적 변화를 준다. 단순한 범위·공격력·주기 증가는 공통 패시브가 담당하고, 아래는 **해당 스킬만의 변화**를 정리한 것이다. 레벨별 수치는 부록 A-4를 본다.

| 액티브 | 1레벨 | 2레벨 | 3레벨 | 4레벨 | 5레벨 (MAX) |
|---|---|---|---|---|---|
| 🚙 **오프로드** | 필드 끝 면에서 1대 소환되어 정면으로 돌진 | 소환 주기 단축 | 동시에 2대 소환 | 돌진 경로 폭 증가 | 동시에 **3대**로 증가 |
| 🌀 **회전베기** | 본편 기준 n번 타격마다 회전베기 1회 | 필요 타격 횟수 감소 | 회전 범위 증가 | 회전 횟수 +1 (연속 2회전) | **상시 회전베기**: 공격할 때마다 발동 (타격 횟수 조건 없음) |

| ⭐ **스텔라** | 나무를 벨 때 낮은 확률로 별 소환 | 별 생성 확률 증가 | **다른 액티브 스킬도 별을 공격**할 수 있다 | 별 표식 유지 시간 증가 + 별 폭발 범위 증가 | 별을 칠 때 폭발이 **2회 연속** 발생 |
| 💣 **포자폭탄** | 자동으로 포자 폭탄을 던져 연막 형성 | 연막 유지 시간 증가 | 연막 범위 증가 | 동시에 2개 투하 | 연막이 **겹치면 지속 피해 중첩** |

### 레벨 구조와 계산 규칙

> 📈 **카드마다 숫자 하나(MAX 누적 효과)만 정한다.** 레벨별 증가량은 부록 A-5의 곡선(레벨 몫)을 곱해 자동으로 계산한다. 증가량은 레벨 가격 배율과 같은 비율로 커지므로, 비싼 레벨일수록 그만큼 더 큰 보상이 돌아온다.

| 규칙 | 내용 |
|---|---|
| 🎯 **입력 값** | 카드마다 **MAX 누적 효과**(예: 이동속도 +30%) 하나만 정한다. 레벨별 증가량 = MAX 누적 효과 × 레벨 몫 |
| 📈 **증가폭형 7종** | 범위, 공격속도, 지속 피해, 스태미너 회복, 최대 스태미너, 유예 시간, 피해 쿨다운. 레벨 V의 몫(30%)이 곧 MAX 보정이다. 추가 효과는 없다 |
| 🧩 **조건부형 4종** | 공격력, 유지 시간, 이동속도, 골드 획득. 레벨 V의 몫에 더해 조건부 효과가 붙는다 (아래 MAX 효과) |
| 🪙 **골드 획득 증가 (예외)** | 본전 시점을 보장하기 위해 레벨별 증가율(+5% / +7% / +8% / +12% / +20%)을 그대로 유지한다 |
| ➕ **합산/곱연산** | 같은 능력치를 올리는 효과(같은 카드의 레벨 누적, 공격력 증가 + 유리 대포 등)는 증가율을 더해 한 번에 적용하고, 서로 다른 계열(공격력 × 지속 피해)은 각각 더한 뒤 곱한다. 최종값 = 기본값 × (1 + 같은 계열 증가율 합) × (1 + 다른 계열 증가율 합) |
| 🔢 **정수형** | 스태미너 회복, 최대 스태미너는 누적값을 반올림해 정수로 맞춘다 |
| 🚫 **합산 상한** | 이동속도, 유예 시간, 피해 쿨다운은 루비(인내의 시간 등)와 겹치므로 합산 상한을 둔다 |
| ☠️ **지속 피해 증가** | MAX 누적 효과를 공격력 증가보다 낮게 설정한다 |

> 🏁 **5레벨(MAX) 효과의 원칙**: 5레벨에 도달하면 일반 레벨 증가분에 더해 MAX 효과를 얻는다. 밸런스 부담을 줄이기 위해 **새 규칙을 만들지 않고, 같은 스탯 축 안에서 수치 하나로 조절할 수 있는 효과**로만 구성한다. 대부분은 증가폭 보정이고, 조건부 효과는 4종이다.
> - 💪 공격력: 나무 수가 임계치 이상일 때 추가 증가 (위기 시 강해짐)
> - ⏳ 유지 시간: 지속형 스킬로 나무를 처치하면 유지 시간 소량 연장
> - 👟 이동속도: 이동 중 공격속도 소량 증가
> - 🪙 골드 획득: 웨이브 클리어 시 고정 골드 보너스

## 6-4. 루비 5종

> ❤️ 루비 카드는 강한 버프와 디메리트를 함께 가지며 업그레이드가 없다. 레벨 대신 `±`로 표기한다. 구매하면 해당 런이 끝날 때까지 유지된다. **보유 수 제한은 두지 않는다**(선택은 유저의 몫). 웨이브와 무관하게 첫 선택을 제외한 어느 선택 단계에서나 등급 비중에 따라 확률적으로 노출된다(루비는 가장 낮은 비중). 이미 보유한 루비와 배타 그룹 카드는 제외한다. 이른 노출로 루비가 있다는 인식을 주는 것도 목적이다.

| 루비 카드 | 버프 | 디메리트 | 설명 문구 |
|---|---|---|---|
| 💸 **바겐 세일!** | **카드 가격이 반값**으로 할인된다 (유료 구매 전체에 적용, 무료 카드는 해당 없음, 소수점은 올림) | **리롤(새로운 카드로 교체)을 더 이상 할 수 없다**. 제시된 카드 중에서만 구매하거나 건너뛸 수 있다 | 카드 가격이 반값이 된다. 대신 카드 교체를 할 수 없다. |
| 💥 **유리 대포** | 도끼와 모든 스킬의 **공격력이 대폭 증가**한다 | **최대 스태미너가 감소**한다 (현재 스태미너는 새 최대치를 넘지 않도록 조정) | 공격력이 대폭 증가한다. 대신 최대 스태미너가 감소한다. |
| ⏳ **인내의 시간** | 임계치 초과 후 첫 피해까지의 **유예 시간이 대폭 증가**한다 | **임계치 T가 감소**한다 (스폰 상한도 감소한 임계치 + 알파를 따라 함께 낮아진다) | 유예 시간이 대폭 증가한다. 대신 임계치가 감소한다. |
| 🎟️ **VIP 회원권** | **리롤 비용이 무료**가 된다 (리롤을 제한 없이 할 수 있다) | **카드 가격이 대폭 증가**한다 | 교체 비용이 없어진다. 대신 카드 가격이 대폭 증가한다. |
| ➕ **다다익선** | 도끼 공격과 모든 액티브 스킬의 **발동 수가 한 번 더 늘어난다** (도끼 공격은 연속 2회 타격, 충격파는 바로 뒤이어 한 번 더 발사, 개수가 있는 스킬은 +1개) | **나무 스폰 속도가 증가**한다 | 도끼 공격과 모든 스킬의 발동 수가 증가한다. 대신 나무 스폰 속도가 증가한다. |

> 🧪 **루비 설계 메모**: 로켓래츠의 "강한 이득 + 불리한 대가" 특성을 참고한다. 조합이 되는 특성이 아니므로 독립 풀로 둔다. 디메리트 후보: 이동속도 감소, 공격력 감소, 나무 생성률 증가 등. 루비는 5종으로 확정하며 추가하지 않는다. 루비는 클리어에 필수인 카드가 아니라, 특정 덱에서 시너지를 내는 선택지여야 한다 (수요 곡선은 루비 없이 설계).

# 🏔️ 7. 티어·엔딩·언리밋

## 7-1. 티어 전환

| 항목 | 규칙 |
|---|---|
| 🏔️ **티어 수** | 총 **4단계**. 30웨이브를 4개 구간으로 나눠 가장 적합한 웨이브에서 전환한다 (번호는 부록 A) |
| 📐 **구간(티어 스테이지)** | 티어마다 담당 웨이브 구간(N~M)이 있고, 피해량이 구간별로 다르다 |
| 🔀 **교체** | 지정 웨이브에서 지형 변경 연출과 함께 상위 티어 나무로 교체한다. 기존 나무는 사라지고 새 웨이브의 나무가 새로 스폰된다 |
| 🌀 **연출** | **바닥 타일이 파도치듯 깔리는 신규 연출**이다. 로비 진입 연출(9장)과 **같은 연출을 공용**으로 쓴다. 폭주 구간(마지막 티어) 전에 **별도의 전조 연출은 두지 않는다**: 맵이 바뀌는 것 자체가 연출 역할을 한다 |
| 🚫 **기믹** | 지형 변경은 연출과 비주얼에 한정한다. 스테이지 고유 기믹은 사용하지 않는다 |
| 🔢 **순서** | **카드 선택 → 지형 전환 연출 → 웨이브 시작**. 연출 중에는 웨이브가 진행되지 않은 상태로 대기한다 |
| 📊 **나무 속성** | 나무 HP와 스폰 수치는 부록 A를 따른다. 티어 안에서도 HP가 구간마다 오른다 (1티어: 2타 → 3타 → 4타) |
| 🌳 **나무 비주얼 진화** | 티어를 구성하는 본편 스테이지의 나무 3종을 티어 안의 초기 · 중간 · 후반 구간에 하나씩 배치해 티어 안에서도 나무 모습이 바뀐다. 1티어 Oak (1~2) → Pine (3~5) → Birch (6~7), 2티어 Sporepuff (8~9) → FluffyMycelium (10~12) → Bellpine (13~15), 3티어 Starroot (16~17) → Moonhalo (18~20) → Galaxygrain (21~22), 4티어 Cinder (23~24) → Lavasap (25~27) → Obsidian (28~30). HP는 나무 종류가 아니라 부록 A 구간 표의 값을 따르고, 본편의 SP(실드)·재생은 쓰지 않는다. 구간이 바뀌는 웨이브에서 새 종류가 주력으로 나오고 이전 종류는 그 웨이브에 일부(초안 30%) 남는다 |

## 7-2. 엔딩과 언리밋 모드

> 🏁 **클리어 웨이브**
> - 클리어 웨이브는 **30웨이브**다
> - 30웨이브를 클리어하면 **즉시 런 클리어**
> - 마지막 기믹은 기믹 종류가 다양해지면 추후 적용한다 (적용 시 클리어 웨이브에서 랜덤 1개 발생, 기믹 클리어가 런 클리어 조건)

> ♾️ **언리밋 모드**
> - 런 클리어 즉시 진입한다 (참고: 로켓래츠)
> - 웨이브 표기는 `Unlimit-1`, `Unlimit-2`...
> - 나무는 **스탯만** 점점 강해진다
> - **카드가 나오지 않는다**
> - 골드를 쓸 곳이 없으므로 골드 드롭과 코인 HUD를 숨긴다
> - 빌드가 **몇 웨이브까지 버티는지** 확인하고 학살의 희열을 느끼게 한다

| 런 클리어 연출 (마지막 웨이브에서만) | 내용 |
|---|---|
| 🎥 **줌인** | 목표 처치 수의 마지막 나무(예: 145번째)를 베는 순간 그 나무를 **빠르게 줌인**하며 **슬로우로 부서지는** 모습을 보여준다 |
| 🎥 **줌아웃** | 이후 재빠르게 줌아웃한다 |
| 🌱 **나무 정리** | 남은 나무는 묘목으로 돌아간 뒤 사라지고, 새 나무가 다시 등장한다 |
| ➡️ **전환** | 이 연출 직후 언리밋 모드로 넘어간다. 일반 웨이브에서는 이 연출 없이 묘목 연출만 사용한다 |

# 📜 8. 기록과 결과

## 8-1. 런 기록

> 📜 **로그라이트 요소는 두지 않는다.** 판이 끝나면 능력치, 해금, 재화 등 아무것도 다음 판으로 이어지지 않으며 매 판은 동일한 출발선에서 시작한다. 기록은 순수한 기록일 뿐 밸런스에 영향을 주지 않는다.

#### 🕒 최근 기록

- 가장 **최근 1판**을 보여준다
- 클리어 여부와 무관하게 모든 판이 대상이다 (포기한 판 포함)

#### 🏆 클리어 랭킹

- **1~5순위**를 보여준다
- 대상: 클리어한 판과 게임오버된 판 (**포기한 판은 제외**), 일반 구간(1~30웨이브) 기준
- 정렬: **도달 웨이브가 높은 순** → 같으면 **시간이 짧은 순**
- 비교 시간: 30웨이브를 클리어한 판은 **30웨이브 클리어 시점까지의 시간**, 클리어하지 못한 판은 **게임오버까지의 플레이 시간**

#### ♾️ 언리밋 랭킹

- **1~5순위**를 보여준다
- 대상: **언리밋 모드에 도달한 판만**
- 정렬: **도달 Unlimit 웨이브가 높은 순** → 같으면 **시간이 짧은 순**

> 💾 **세 탭 공통 표시 정보**: 사용한 카드 목록(구매한 카드 + 해금한 히든 카드), 플레이 시간, 도달 웨이브. 저장 시 **30웨이브 클리어 시점의 시간**을 별도로 기록한다 (클리어 랭킹 비교용).
> **플레이 시간의 정의**: 웨이브 전투 시간의 합이다. 카드 선택·연출 시간은 포함하지 않는다.

> 2. **결과를 기록**한다 (결과 화면이 나오기 바로 전)
> 3. 결과 화면 노출 (본 게임 결과 UI의 구조와 연출을 비슷하게 가져간다)

|---|---|---|

# 🚪 9. 모드 진입과 로비

> 🔓 **진입 조건**: `로그라이크 모드`가 해금되면 `메인메뉴`의 버튼이 활성화되고, 클릭하면 진입 연출이 시작된다. **해금 조건**: 본편에서 모든 특성을 해금하고 엔딩을 보았을 때. 본편에 엔딩이 아직 없어 개발 중에는 버튼을 상시 활성화한다.

## 9-1. 진입 연출

| 단계 | 연출 | 내용 |
|---|---|---|
| 1️⃣ | 🌀 **디스토션** | 진입 시점의 화면(메인메뉴 또는 결과 화면)에 디스토션이 발생한다 |
| 2️⃣ | ⬛ **암전** | 화면이 검은색으로 뒤덮인다 |

| 4️⃣ | 🧩 **배경 조립** | 나머지 배경이 퍼즐처럼 하나씩 등장한다 |

> - 바닥 타일 파도는 **신규 연출**이며, 7장 티어 전환의 지형 전환 연출과 **같은 연출을 공용**으로 쓴다
> - 배경 퍼즐 등장은 알파 페이드 조절 또는 셰이더 중 자유롭게 구현한다
> - 런 종료 후에도 같은 연출이 재생된다. 결과 화면에서 확인을 누르면 **결과 화면에서 바로 디스토션**이 걸리며 넘어간다 (메인메뉴를 거치지 않는다)

| 상호작용 대상 | 실행 내용 |

# 🖥️ 10. HUD와 카드 UI

> 🧪 **UI 표기 원칙: 일단 테스트 버튼.** 디자인이 확정되지 않은 UI는 **테스트 버튼으로 표기**하고, 확정되면 실제 UI로 교체한다.

## 10-1. 전투 HUD (하단 중앙)

| HUD | 배치 | 표시 값 | 디자인 규칙 |
|---|---|---|---|
| ⚡ **스태미너 바** | 하단 중앙 | 현재 스태미너 | 본 게임의 스태미너 바를 그대로 사용한다 |
| 🌲 **임계치 바** | 하단 중앙, 스태미너 바의 위 또는 아래 | 필드의 **현재 나무 수 / 현재 임계치 T** (인내의 시간 등으로 감소한 값 반영) | 스태미너 바와 통일감을 주고 **색만 다르게** 표현한다. 유예 시간이 흘러가는 진행도 이 바에서 표현한다 (방식은 디자인 단계에서 결정) |
| 🪙 **코인 HUD** | 하단 중앙, 바 기준 왼쪽 윗부분 | 현재 보유 골드 | 본 게임의 코인 HUD를 그대로 사용한다 |

## 10-2. 카드 HUD

| 항목 | 규칙 |
|---|---|
| 🃏 **노드 UI** | 카드 연출은 **특성 트리에 사용된 노드 UI**를 사용한다 |
| 🖼️ **프레임** | 현재 노드 프레임은 그림 이미지와 딱 맞으므로, 카드에서는 내부 이미지보다 **조금 더 넓은 프레임**을 사용한다 |
| ✨ **셰이더** | **희귀 나무에 사용된 셰이더**를 참고해 인벤토리 슬롯처럼 구성한다 |
| 🔢 **레벨 표기** | 이미지 아래 중앙에 `I`, `II`, `III`, `IV`, `MAX`. **구매 후 레벨**이며 처음 구매할 때는 `I`로 "1단계 카드를 구매한다"는 인식을 준다. 처음 구매와 업그레이드가 명확히 구분된다 |
| ❤️ **루비 표기** | 레벨 대신 `±` 기호를 표기한다 (버프와 디버프를 모두 가진 카드라는 의미) |

### 카드 선택 화면 구성

> 🖼️ **카드는 깔끔하게, 설명은 카드 아래의 설명 패널에서 보여 준다.** 카드 본체에는 텍스트를 넣지 않는다 (스케치 기반).

| 영역 | 구성 |
|---|---|
| 🃏 **카드 본체** | 둥근 프레임(등급 표현) 안에 **카드 이미지**, 하단 중앙에 **레벨 아이콘**(`I`~`IV`, `MAX`, 루비는 `±`)만 둔다 |
| 🪙 **가격** | 카드 우상단 모서리에 **코인 아이콘 + 숫자**를 둔다. 골드가 부족하면 숫자를 붉은색으로, 무료 카드는 `무료`로 표시한다 |
| 📝 **설명 패널** | 카드 아래에 넓은 박스 하나를 둔다. 선택 커서가 올라간 카드의 내용을 표시한다. 첫 줄에 **카드 이름**, 아래에 설명 문구 |

| 카드 상태 | 설명 패널 내용 |
|---|---|
| 🆕 **처음 구매** | 이름 / 기본 설명 한 줄 |
| ⬆️ **업그레이드 (II~IV)** | 이름 / 기본 설명 / **이번 레벨의 변화 한 줄** (액티브는 변화 문구, 패시브는 누적 수치 변화) |
| 💚 **에메랄드(MAX)** | 이름 / 기본 설명 / MAX 효과 한 줄 |
| 💎 **프리즘** | 이름(`A + B`) / 조합 설명 |
| ❤️ **루비** | 이름 / 버프 한 줄 / **디메리트 한 줄(붉은색)** |

> ✅ **확정**: 설명 패널에 레벨 I~V 전체 효과 목록은 표시하지 않는다. 카드를 사면 찍히는 레벨의 효과만 보여 주고, MAX 효과는 에메랄드 카드에서만 공개된다. 보유 카드 확인 화면에서 다음 레벨 효과를 미리 보여 주지 않고, 다음 선택 화면에서 확인한다.

### 카드 선택 화면 조작

| 항목 | 규칙 |
|---|---|
| 🎮 **입력** | 게임패드로 조작할 수 있어야 한다 |
| 👆 **시작 상태** | 화면이 열리면 **제일 왼쪽 카드가 호버**된 상태로 시작한다 |
| ▭ **커서** | 선택 커서는 **CursorBox UI**(OverPopupUI에 있는 것)를 사용한다 |
| 🔴 **골드 부족** | 골드가 부족한 카드는 **가격 글씨를 붉은색**으로 띄워 구매할 수 없다고 알린다 |
| 🔒 **감정 버튼 잠금** | 감정사가 등장했지만 감정할 수 없는 상태면 감정 버튼을 비활성(잠금 표시)으로 둔다 (4-4) |

### 보유 카드 확인

| 항목 | 규칙 |
|---|---|
| 📋 **내용** | 전투 중에도 보유 카드 종류와 레벨을 확인할 수 있어야 한다. 카드를 고르면 설명 패널에 해당 카드의 **현재 레벨 효과**를 표시한다. 카드 선택 화면에서는 그 카드를 사면 찍히는 레벨의 설명을 보여 준다 |
| 🖱️ **키보드·마우스** | 마우스로 클릭해서 볼 수 있는 UI를 제공한다 |
| 🎮 **게임패드** | 특정 키를 누르면 표시된다 (키는 아직 정하지 않았다) |

## 10-3. 카드 UI 연출

| 연출 | 내용 | 상태 |
|---|---|---|
| 🃏 **카드 목록 연출** | — | 🚧 미확정 |
| 🔄 **기본 등장** | 카드가 **뒤집히는 모션**을 구현할 수 있으면 적용한다. 특정 방향에서 등장하는 동시에 화면 방향으로 정면이 된다. **빠르게** 진행되어야 하며 답답하면 안 된다. 순차적으로 N장에 이어진다 | ✅ 확정 |

| ✨ **레어 카드 등장** | 희귀 셰이더로 화려하게 번쩍이며 변경된다. 프레임이 **디졸브**되어 일반 프레임이 점차 가려진다 (**아래에서 위로** 스윽). 카드 윗부분에서는 번쩍하며 시선을 뺏는다 | ✅ 확정 |
| ⚪ **일반 등급 카드 선택** | — | 🚧 미확정 |
| 🌟 **레어 등급 카드 선택** | — | 🚧 미확정 |
| 🔍 **카드 감정** | 돋보기 스프라이트가 카드 여러 곳을 조사한 뒤 카드가 번쩍이고, 레벨 표기(스티커) 부분이 뜯기는 표시가 된다. 유저가 마우스로 잡아 끌어내리면 결과가 공개된다 (게임패드는 스틱 입력). 결과는 미리 확정되어 있다 | 🟡 연출 방식 확정, 세부 연출 미정 |
| 🔥 **배타 카드 소멸** | 상충하는 카드를 구매하면, **같은 선택에 함께 제시되어 있던 상충 카드가 소멸하는 연출**을 재생한다 (예: 불에 타서 사라진다, 찢어진다). 구매한 카드의 연출 뒤에 재생하고 **빠르게** 진행해 답답하지 않게 한다. 연출이 끝난 뒤 전투(티어 전환 웨이브는 지형 전환 연출)로 넘어간다 | 🟡 소멸 연출은 확정, 방식은 아이디어 수집 중 |

## A-3. 수요 곡선의 설계 근거

> 🎯 **목표**: 수요(초당 스폰 × 나무 HP)가 빌드의 처치력과 맞물리도록 정한다. 액티브 없이 도끼만 풀업한 빌드는 2티어까지만 버티고 3티어부터 터무니없이 힘들다. 4티어는 액티브 1개를 MAX로 만든 것만으로는 깰 수 없고, 22웨이브까지 만든 빌드에 4티어 수입으로 구매를 이어 두 번째 액티브까지 키워야 겨우 따라간다. 빌드가 잘 맞으면 여유가 생기고 학살의 재미를 느낀다.

| 원리 | 내용 |
|---|---|
| 📏 **단위** | 도끼 공격력 10을 기준으로 한 정수 단위다. 나무 HP ÷ 도끼 공격력이 기본 도끼의 필요 타수다 (예: HP 20 = 2타) |
| ⚖️ **수요 곡선** | 수요(HP/초) = 초당 스폰 × 나무 HP. 스폰 주기는 1 ÷ 초당 스폰이다 |
| 🪓 **기준 처치력 (HP/초)** | 기본 도끼 12 / 도끼 풀업(공격력 +100%, 공격속도 +60%, 액티브 없음) 약 43 / 액티브 1개 MAX 약 200 / 액티브 1개 MAX + 패시브 MAX 약 650. 액티브 5레벨의 처치력이 모두 약 200이 되도록 카드 수치를 맞춘다 |
| 🧭 **티어별 목표** | 1티어: 도끼에 카드 몇 장으로 유지 / 2티어: 도끼 풀업이 한계(15웨이브에서 수요 1.0배) / 3티어: 도끼 풀업으로 불가(수요 2.9~4.8배) / 4티어: 액티브 1개 MAX 단독으로 불가(수요 2.6~4.9배), 22웨이브까지 만든 빌드(처치력 약 650)에 4티어 구매(웨이브당 1장)를 더해 두 번째 액티브까지 키워야 겨우 가능(수요 ÷ 처치력 0.73~0.93, 한 웨이브 내 허용 오차 약 1.4배 안쪽) |
| ⏳ **웨이브 길이** | 목표 처치 수 = 초당 스폰 × 약 60초 (5그루 단위 반올림, 1웨이브 30그루). 모든 웨이브를 약 60초로 맞춘다 (시간 제한이 아니라 목표 처치 수를 정하는 환산 기준이며, 클리어는 어디까지나 목표 처치 수 달성이다). **기록되는 플레이 시간은 웨이브 전투 시간의 합**이며 카드 선택·연출 시간은 포함하지 않는다. 목표는 30웨이브 전투 시간의 합이 35분 이내다. 필드가 비어 시작하고 스폰이 처치를 앞서므로, 현재 규칙에서는 아무리 빠른 빌드도 웨이브당 약 60초 밑으로 내려갈 수 없다 (30웨이브 최소 30분). 처치가 모자라면 더 길어지고, 35분까지 여유는 전체 지연 합계 5분(웨이브당 평균 10초)이다 |
| 💰 **골드 수급** | 나무 1그루당 1티어 2골드 / 2티어 1.75골드 / 3~4티어 1골드 (소수는 웨이브 종료 시 합산해 반올림). 웨이브 수입은 60 → 145로 늘고(2티어 진입에서 100 → 88로 소폭 꺾인다), 누적은 22웨이브까지 약 2,015, 30웨이브까지 약 3,110이다. 60초 기준으로 처치 수가 약 20% 늘어난 만큼 나무당 골드를 낮춰 총량을 유지했다. 1웨이브 수입 60은 브론즈 카드 1레벨 가격(60)과 같다 |
| 🌲 **임계치와 상한** | 임계치 T 40, 스폰 상한 52 (T + 12). 가득 차기 전에 경고 구간이 생긴다 |
| 📉 **안전해지는 조건** | 상한에 닿아도 한 그루 죽으면 즉시 재스폰되므로, 필드가 임계치 아래로 내려가려면 **처치 속도가 스폰 속도보다 빨라야** 한다. 버티는 시간 = 임계치 도달 시간 + 유예 시간 + (필요 피해 횟수 − 1) × 쿨다운 |
| ⚡ **스태미너** | 최대 100, 티어별 피해 3 / 6 / 10 / 15. 스태미너는 웨이브 간에 유지되므로 실제로는 A-2 표보다 버티는 시간이 더 짧다 |

> ⚠️ **이 표의 가정**
> - 필드가 비어 있는 상태에서 시작하고 스태미너 100이 가득 찬 상태를 기준으로 한다
> - "방치 시 버티는 시간"은 처치 속도가 0인 최악의 경우다. 실제로는 일부 처치로 이보다 더 오래 버틴다
> - 플레이어의 실제 초당 처치 수는 측정한 값이 아니다. 기준 처치력은 이동 가동률 70%, 광역기 동시 타격 3~6그루, 필드가 가득 찬 상태를 가정한 추정이다. 프로토타입에서 측정해 수요 곡선을 다시 맞춘다. 4티어 HP(280 / 340 / 420)는 22웨이브 이후에도 웨이브당 1장씩 구매해 두 번째 액티브를 23웨이브부터 키운다는 가정의 중간값이며 실측 후 조정한다

## A-5. 공통 패시브 레벨별 값

> 📈 레벨별 누적 효과 = MAX 누적 × 누적 달성률 (12% / 27% / 46% / 70% / 100%). 정수형은 누적값을 반올림한다. 골드 획득 증가는 예외로 레벨별 증가율을 그대로 쓴다. 계산 규칙은 6-3을 본다.

# 📝 부록 B. 카드 기획 시트 양식

> 📝 카드를 한 장 기획할 때 채울 항목 목록이다. 개발용 데이터 구조가 아니라 **기획자가 카드 한 장마다 적어야 할 내용**을 정리했다. 액티브, 패시브, 루비 모두 같은 양식을 쓴다.

## B-1. 카드 기본 양식

| 구분 | 항목 | 작성 규칙 |
|---|---|---|
| 🆔 **기본** | 카드 이름 | 자유롭게 짓는다. **이름에 스킬 이름을 넣지 않는다** |
| 🆔 **기본** | 설명 / 이미지 | 카드에 표시되는 텍스트와 이미지 (작성 규칙은 5-6) |
| 🏷️ **분류** | 카드 종류 | 액티브 / 공통 패시브 / 루비 |
| 🏷️ **분류** | 내부 태그 | 액티브는 자기 스킬을 가리키는 태그 (예: `Shockwave`). **공통 패시브는 전체 적용이므로 비운다** |
| 🏷️ **분류** | 지정 등급 | 브론즈 / 실버 / 골드 / 루비. **에메랄드와 프리즘은 자동 부여되므로 직접 지정하지 않는다** |
| 🏷️ **분류** | 배타 그룹 | 같은 그룹 ID를 가진 카드끼리는 **한 판에 한 장만 보유**할 수 있다. 비워 두면 배타 없음. 카드당 그룹은 1개. **조합 재료 카드는 배타 그룹에 넣지 않는다** |
| ⬆️ **레벨** | 레벨 상한 | 모든 카드 5로 고정 (5레벨 = `MAX`). 루비는 해당 없음 |
| ⬆️ **레벨** | 레벨별 효과 | 1레벨부터 상한까지 각 레벨의 효과를 적는다 (공통 패시브는 MAX 누적 효과 하나만 정하고, 레벨별 값은 부록 A-5 곡선으로 계산한다) |
| 💰 **가격** | 레벨별 가격 | 1레벨은 등급별 단가(브론즈는 100 이내), 이후 레벨은 **그 카드에 한해** 단계적으로 오른다 |
| 🔗 **조합** | 조합 대상 | 이 카드가 재료로 쓰이는 조합 목록. 한 카드가 여러 조합에 쓰일 수 있다 |
| ❤️ **루비 전용** | 버프 / 디메리트 | 장점(버프)과 단점(디메리트)을 함께 적는다 |
| 📝 **메모** | 특이사항 | 노출 조건이나 다른 카드와의 관계 등 |

## B-2. 조합 카드 양식 (프리즘)

| 항목 | 작성 규칙 |
|---|---|
| 💎 **이름·설명** | 일반 카드와 동일하게 작성한다. 등급은 프리즘으로 자동 표기된다 |
| 🔗 **필요 카드** | 조합에 필요한 두 카드. 두 카드가 모두 **MAX 레벨**이 되면 조합이 열린다. 조합 카드를 구매해도 재료 카드는 그대로 유지된다. 재료가 겹치는 조합은 한 판에 하나만 만들 수 있다 |
| 🧬 **재료 카드의 기존 능력** | **조합마다 다르다.** 재료의 기존 능력을 사용하지 않는지, 유지하는지, 일부만 쓰는지 조합마다 명시한다 |
| ✨ **조합 효과** | 조합 카드를 구매했을 때 얻는 효과 |
| 💰 **가격** | 조합 카드의 구매 가격 (무료) |
| 🔒 **비공개** | 조합 정보는 게임 내 어느 UI에도 사전 노출하지 않는다 |
