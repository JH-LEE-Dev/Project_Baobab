### 정리·수정
- **수치 단일 관리**: 규칙 장에서 수치를 빼고 부록 A에만 둠 (수치가 여러 장에 흩어져 등급이 어긋나던 문제 방지)
- **등급 불일치 수정**: 옛 설명 문구 표에 남아 있던 낡은 등급(스텔라 골드, 공격속도 실버, 골드 획득 실버, 회전베기·충격파·부메랑·포자폭탄 브론즈)을 도감 표 하나를 기준으로 통일
- **중복 제거**: 등급 지정 개요표, "가중 1: 태그 비율(폐지)" 행 삭제. 카드 목록 3종 표를 카테고리별 표로 통합
- **규칙 정합성**: 스텔라의 타 액티브 별 공격을 "조합 카드로 개방"에서 "레벨 III 효과"로, 배타 그룹 적용 순서를 슬롯 0\~3 구조로, 스태미너 피해량 예시를 3 / 6 / 10 / 15로 수정
- **오타 수정**: 곡해(곱해), 곣이(곧), 몰(몫), 지역 큰 이득 등
- **디자인**: 색 규칙 통일(초록 = 확정, 노랑 = 초안, 빨강 = 미정, 파랑 = 설명, 회색 = 참고), 핵심 수치 대시보드와 목차 추가

## v1.1까지의 형성 과정 (결정 요약)

일자가 기록된 항목만 날짜를 적었다.

### 카드 체계
- 카드 28종 확정: 액티브 7 · 조합(프리즘) 5 · 공통 패시브 11 · 루비 5
- 모든 카드 최대 5레벨(MAX) 통일, MAX와 프리즘은 무료, 루비는 레벨 없음
- 조합 5종 확정 (2026-10-13): 회전베기 + 충격파(360도 충격파로 대체), 부메랑 + 충격파(부메랑·충격파 유지 + 추가 충격파), 회전베기 + 부메랑(부메랑 타격마다 회전베기), 스텔라 + 포자폭탄(별 표식에 지속 피해, 죽을 때 포자 폭발), 스텔라 + 드론(별 사이 빔, 9개에서 노바)
- 다중 타격 카드와 드론 + 다중 타격 조합 폐지, 드론에 체인 라이트닝 복구
- 스텔라가 다른 액티브의 별 공격을 허용하는 능력은 조합 대신 스텔라 레벨 III 효과로 이동
- 액티브 전용 패시브는 도입하지 않음. 카드 가격 할인·리롤 비용 감소는 루비 카드로 처리
- 카드 감정(한 판 한 번의 도박) 추가, 감정사 골드 부족 시 버튼 잠금·기회 소멸 확정
- 배타 그룹(가격 정책 / 스텔라 조합 / 삼각 조합)과 소멸 연출 추가

### 밸런스 (모두 초안)
- 도끼 공격력 10 정수 단위, 쿨타임 0.6초, 단일 타격 (다중 타격은 카드·기본 능력 모두 없음)
- 나무 HP를 티어 배율에서 **구간별 절대값**으로 변경 (20 → 310), 티어 안에서도 HP 상승
- 나무 비주얼을 본편 스테이지의 나무 12종으로 티어 안에서 진화시킴 (SP·재생은 쓰지 않음)
- 초당 스폰 0.50 → 2.45, 목표 처치 수 = 초당 스폰 × 약 60초 (시간 제한이 아니라 환산 기준), 기록 시간은 웨이브 전투 시간의 합
- 나무당 골드 2 / 1.75 / 1 / 1, 누적 약 3,110
- 카드 등급: 액티브 7종 모두 실버, 핵심 딜 패시브와 골드 획득 증가는 브론즈, 첫 무료 카드는 액티브 중 선택
- 패시브 11종의 MAX 누적 값과 레벨별 값, 액티브 7종의 레벨별 수치와 추정 처치력
- 드론은 레이저 피해를 낮게(7) 두고 기수·연쇄·주기로 성장
- 액티브 노출 보정: 선택마다 액티브 최소 1장 보장(슬롯 2), 구매 가능 카드 2장 보장은 슬롯 3으로 이동 (액티브가 구매 불가이면 구매 가능한 브론즈 카드 2장)
- 난이도 목표: 도끼 풀업은 2티어까지, 3티어부터 불가, 4티어는 액티브 1개 MAX + 패시브 MAX로 겨우 클리어

### 아직 정해지지 않은 것 (v2.0 부록 C 참고)
- 보충 스폰 도입 여부, 목표 처치 수 환산 기준 유지 여부
- 루비 카드 추가, 노출 가중치 수치, 스텔라 별 표식 효과
- 연출 수치(진입 · 카드 · 코인), 게임패드 보유 카드 키, 마지막 기믹
- 코드 반영 (구간 표, 도끼 10과 스킬 기준값 주입, 스킬 튜닝 SO 교체, 카드 등급 데이터)
