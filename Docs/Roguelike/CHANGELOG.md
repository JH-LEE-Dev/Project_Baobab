# 로그라이크 모드 기획서 패치 노트

> 이 폴더에는 **현재 버전과 직전 버전**만 둔다. 더 오래된 버전의 본문은 없으므로, 버전을 건너뛴 경우에도 적용할 수 있도록 이 문서에 **버전별 변경점을 전/후 값까지** 적는다.

## 2. 패치 적용 방법

1. **한 버전씩 순서대로** 적용한다: v1.1 → v2.0 → v2.1 → (이후 버전). 각 패치는 3장\~4장에 있다.
2. **중간 버전을 건너뛰면** 5장의 "누적 변경표"를 쓴다. 건너뛴 패치를 모두 합친 결과(최종 값과 규칙)가 적혀 있다.
3. 패치는 세 종류로 적는다: **구조 변경**(장 이동·병합·삭제), **값 변경**(전 → 후), **규칙 변경**(문구 의미가 바뀐 것). 영향받는 **코드 항목**도 따로 적는다.
4. 값은 모두 도끼 공격력 10 기준 정수 단위다. 위치는 해당 버전 문서의 장 번호로 적는다.

## 6. 앞으로 패치 노트를 쓰는 규칙

새 버전을 내보낼 때 아래를 이 문서에 추가한다.

1. 버전 목록 표에 한 줄을 추가하고, 이 폴더에는 **현재와 직전 두 버전만 남긴다** (가장 오래된 md 삭제)
2. 새 패치 절에 **구조 변경(장 매핑) · 값 변경(전 → 후, 문서 위치 포함) · 규칙 변경(전 → 후) · 정정 사항 · 부록 C 변경 · 코드 영향**을 적는다
3. 5장의 누적 변경표를 **가장 오래된 보관 대상 버전(지금은 v1.1) 기준**으로 갱신해, 건너뛴 버전이 있어도 최종 결과를 알 수 있게 한다
4. 값이 바뀌지 않은 항목은 "변경 없음"으로 한 줄 남겨 혼동을 막는다
