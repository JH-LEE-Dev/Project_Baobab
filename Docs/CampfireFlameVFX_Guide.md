# 모닥불 불꽃 VFX 가이드

휴식처(RestArea) 모닥불에 불이 지펴지는 연출(`VFX_CampfireFlame`)의 구성, 게임 연결 상태, 튜닝 방법을 정리한 문서입니다.

- 이펙트와 휴식처 연결(`RestAreaVisual` 필드 1개와 호출 2줄, 프리팹 자식 오브젝트)까지 **Presentation Layer 안에서 모두 적용되어 있습니다.** Application Layer 수정은 필요 없습니다.
- 휴식처가 열리면(`RestAreaVisual.SetOpen(true)`) `campfireRevealDelay`(0.12초) 뒤 점화 시퀀스가 시작되고, 닫히면 즉시 멈춥니다. **소화 연출은 없습니다.**
- 시뮬레이션(웹)으로 연출을 승인받은 뒤 만들었습니다. 아지랑이(열 왜곡)와 밤 분위기(주변 어두움, 돌 재조명)는 승인 시안에서 제외했습니다.

### 위치와 정렬

| 항목 | 값 |
|---|---|
| 원점 | `CampfireFlame` 오브젝트 위치 = RestArea = CampFire 위치 |
| 불꽃 밑줄 | 원점 위 8px(처음 9px였으나 떠 보여 1px 내림), 중심 열은 원점 열. 점화 섬광, 불씨, 연기 시작 높이도 같이 1px 내렸다. 모닥불 그림(32x32, 피벗 중앙)이 원점 위 11px에 놓이기 때문이다 |
| 몸통 정렬 | 레이어 `Objects`, 순서 = Back 조각의 `ComputeSortingOrder(원점 Y)` + 1 (Back 0 / 불꽃 +1 / Front +2) |
| 바닥 불빛 정렬 | 레이어 `Indicators`, 순서 0 (범위 타원 -1 바로 위, 모든 사물 밑) |

## 2. 연출 구성

| 요소 | 내용 |
|---|---|
| 불꽃 몸통 | 21x36 열 격자를 30Hz 고정 간격으로 갱신한다. 열이 위로 올라가며 식고 좌우로 흔들린다. 4단계 색(적갈 -> 주황 -> 노랑 -> 밝은 노랑). 아래에 불이 없는 칸은 그리지 않는다 |
| 불꽃 밑면 | 바닥 4줄을 타원 마스크로 깎고, 맨 아랫줄은 가장 어두운 색으로 한 칸 걸러 찍으며(15Hz로 흐름) 1줄은 2단계, 2줄은 3단계까지만 쓴다. 잘린 단면 대신 장작에 스며드는 느낌이다 |
| 숯불 | 장작 위 18픽셀. 값 노이즈로 노랑/주황/적갈로 깜빡인다 |
| 점화(0.9초) | 별 섬광(0.06~0.22초) -> 불똥 18개 + 불씨 8개 -> 불꽃이 EaseOutBack으로 자란다(0.1~0.72초) |
| 불씨 | 초당 약 8개(점화 강도에 비례). `.` `+` `x` `●` `◆`가 50/20/17/7/6%. 수명 50%부터 `●`/`◆`는 `+`로, 75%부터는 `.`로 줄고, 70%부터 30Hz로 깜빡인다 |
| 불똥(lick) | 불꽃 위쪽에서 초당 약 1.8개 떨어져 나가는 `+` -> `.` |
| 장작 튀김(pop) | 점화 후 2.6초 뒤 처음, 이후 1.6~4초마다 5~8개가 포물선으로 튀고 불꽃이 순간 커진다 |
| 연기 | 초당 1개. `.` 뒤 `●`로, 바이어 디더로 성글어지며 올라간다 |
| 바닥 불빛 | 반지름 46 x 23px 타원을 4단계 디더로 가산 혼합. 불꽃 세기에 따라 깜빡이며 15Hz로 갱신한다 |

## 3. 구현 방식

- 모든 입자는 고정 크기 구조체 배열(112칸)이라 **재생 중 힙 할당이 없다.** 난수는 자체 xorshift다.
- 쿼드 버퍼(`PixelQuadBuffer`)는 몸통용(1500쿼드)과 바닥 불빛용(3600쿼드) 두 개를 static으로 공유한다. 직전과 같은 그림이면 업로드를 건너뛴다(`PixelPainter.Commit`).
- 화면 밖이면 그리기만 건너뛴다(`PixelVfxCulling`). 시뮬레이션은 가벼워서 계속 돌려 다시 들어와도 불꽃이 이어진다.
- 격자 냉각 계수, 원천 마스크, 숯불 위치, 바닥 불빛 감쇠는 `Awake`에서 한 번만 계산한다. 정점 색은 6색 x 5발광 등급으로 미리 만들어 두고 선형 색 공간이면 선형으로 변환한다.
- `SetOpen(true)`가 이미 열린 상태에서 오브젝트가 다시 켜질 때도(던전 재진입) 점화가 처음부터 다시 시작한다(`OnEnable`).
- 이 이펙트는 `_CameraSortingLayerTexture`를 읽지 않으므로 `SortingLayerTextureUser`는 필요 없다.

## 4. 픽셀 규칙 검수표

| 규칙 | 적용 | 비고 |
|---|---|---|
| JAGGIES | 적용 | 모든 도형이 정수 격자 칸이다. 불꽃 밑면 곡선은 칸 판정(타원 마스크)으로만 만든다 |
| DOUBLE PIXEL | 적용 | 선 그리기가 없다. 섬광 광선은 1px 직선이고 대각 광선은 칸이 겹치지 않는다 |
| HUGGING | 적용 | 평행한 선이 없다. 불꽃 가장자리는 열 칸 단위 계단이다 |
| 입자 모양 | 적용 | 불씨, 불똥, 장작 튀김은 `.` `+` `x` `●` `◆`만 `PixelPainter.SpacedShape`로 그린다. 연기는 `.`와 `●`만 쓰고 같은 모양을 디더로 깎아 그린다 |
| 입자 균형(간격) | 적용 | 입자끼리 겹치거나 바로 맞닿으면(간격 0칸) 뒤에 그린 쪽을 `.`로 줄이고, `.`도 맞닿으면 생략한다. 다른 입자가 이어 붙어 `x`+`+`의 합집합 같은 비대칭 덩어리가 되는 것을 막는다. 간격이 1칸 이상이면 그대로 그린다. 이 규칙은 모닥불에만 적용했고, `Shape`를 쓰는 다른 이펙트(스텔라, 수리 스파크, 오프로드 레인, 헤이스트)는 아직 아니다 |
| 30fps 이상 | 적용 | 몸통은 매 프레임 다시 그린다(격자는 30Hz 갱신). 불씨 깜빡임 30Hz. 바닥 불빛만 15Hz다(은은한 깜빡임이라 입자가 아님) |

## 5. 시뮬레이션과 달라진 점

| 항목 | 시뮬레이션 | 제작 | 이유 |
|---|---|---|---|
| 바닥 불빛 | 바닥과 돌을 곱하기/더하기로 밝힘 + 밤 분위기 | 바닥에만 주황색을 **가산 혼합**(알파 0.22 x 4단계) | 이 프로젝트에는 라이트가 없다. 돌, 나무, 캐릭터는 밝히지 못한다 |
| 발광 세기 | 0.3 ~ 1.0 사이 9가지 | 5등급(0.30/0.45/0.60/0.85/1.0) | 정점 색 테이블을 미리 만들어 두기 위해 가장 가까운 등급으로 묶었다 |
| 연기 색 | 밤/낮 계산 후 높이에 따라 따뜻한 색 번짐 | 낮 기준 3색 x 4단계 번짐 | 게임에 밤 연출이 없다 |
| 블룸 | 웹 캔버스 블러 | 정점 알파 발광 + 게임의 블룸 포스트 프로세싱 | 실제 밝기는 게임에서 확인해야 한다 |
| 아지랑이, 소화 연출 | 있음 | 없음 | 승인 시안에서 제외 |

## 6. 튜닝

프리팹 `OffRoadVehicle` > `RestArea` > `CampfireFlame`의 `VFX_CampfireFlame` 인스펙터 값입니다.

| 필드 | 기본 | 용도 |
|---|---|---|
| `glowScale` | 1.0 | 정점 알파(발광 세기) 배율(0 ~ 2). 블룸이 과하거나 약할 때 가장 먼저 만질 값 |
| `groundGlowStrength` | 0.22 | 바닥 불빛 알파 최대값(0 ~ 1). 0이면 바닥 불빛이 꺼진다 |
| `sortingOrderOffset` | 1 | Back 조각 정렬 순서 기준 추가 오프셋 |
| `glowSortingLayerName` / `glowSortingOrder` | Indicators / 0 | 바닥 불빛 정렬 |

코드 상수로 조정하는 값(필요하면 요청 주세요): 격자 크기와 냉각 계수(`FireStep`, `BuildTables`), 불씨 초당 개수(8), 장작 튀김 간격, 바닥 불빛 반지름(`GlowRadiusX/Y`), 점화 길이(0.9초).

## 7. 확인 방법

1. 메뉴 `LumberBoy/VFX/Build Campfire Flame`을 실행하면 머티리얼, 프리팹 연결이 같은 결과로 다시 맞춰진다(이미 적용되어 있음).
2. 휴식 특성이 있는 상태로 던전에 들어가 휴식처가 열리는 순간을 본다.
3. 확인할 항목
   - 불꽃 밑면이 모닥불 장작 위에 놓이는가(밑줄이 장작에서 뜨거나 파묻히지 않는가).
   - 돌 그림(Front)이 불꽃 밑을 가리고, 캐릭터가 모닥불 뒤/앞을 지날 때 정렬이 자연스러운가.
   - 블룸 밝기가 주변 이펙트와 비슷한가(`glowScale`), 바닥 불빛이 은은한가(`groundGlowStrength`).
   - 휴식처 범위 밖으로 벗어났다 돌아와도 불꽃이 이어지는가.

## 8. 미검증 항목 (게임에서 확인이 필요합니다)

| 항목 | 상태 |
|---|---|
| 게임 플레이 중 재생 | 에디터 편집 모드에서 점화 시퀀스를 시간대별(0.08~4.5초)로 렌더해 모양과 위치를 확인했다(발광 배율 1 기준). 플레이 모드, 실제 휴식처 열림/닫힘 재생은 하지 않았다 |
| 블룸과 HDR 밝기 | 렌더 확인은 발광 배율을 1로 낮춘 상태로 했다. `GlowMax` 2.2로 낮춘 뒤의 블룸 세기와 색 포화는 게임 화면에서 봐야 한다 |
| 앞/뒤 정렬 | Back +1로 맞췄으나 캐릭터, 나무와 겹칠 때의 앞/뒤는 미확인 |
| 바닥 불빛 | 가산 혼합 색과 세기(0.22)는 추정값이다. 바닥 타일 색에 따라 달라 보일 수 있다 |
| 닫힘, 재진입 | `SetOpen(false)` 즉시 정지와 던전 재진입 시 점화 재시작은 코드로만 확인했다 |
| 성능 | 프로파일링하지 않았다. 몸통 쿼드는 수백 개, 바닥 불빛은 15Hz로 최대 수천 칸을 검사하고 쿼드는 약 1000~2000개 규모로 추정한다. 할당은 없다 |
